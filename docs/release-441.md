# COWMATA Annotator 4.4.1（发布包 COWMATA-Pro-4.4.1）


### F:\ 目录对齐
- 数据、台账、模型、决策统一到 `1_下载器 / 2_标注器 / 3_训练器 / 4_决策器`；旧位置（`F:\扬大_高邮牧场`、`F:\牛舍_现场记录`）自动换到新结构，不再引用旧路径。
- 上传服务器与本软件只写 `1_下载器\扬大_高邮牧场\台账`（样本试验台账 / 产犊登记 / 设备台账 / 待产犊台账）。
- 自动标注模型默认查找 `3_训练器\产犊\模型\<最新版本>\行为识别`；协作数据包放在 `2_标注器\科牧特_协作标注`。
- 台账、待核对V2 不再被当作工程目录扫描。

### 下载：一个按钮
- 去掉手动 / 自动 / 定时三种方式：点“下载”即按样本试验台账自动下载到当前时刻，每轮间隔 1 分钟；再点“暂停”。
- 暂停时删除未完成的临时文件；再次下载从断点继续，已下载的完整文件跳过。
- 表格精简为 状态 / 牛号 / 设备号 / 分类 / 佩戴 / 文件；重新下载改为右键或“更多”。
- 打开下载器与每轮开始时核对待产犊：台账补上产犊时间的，文件立即移到产犊或孕晚期。
- 下载期间自动启动决策器（`4_决策器\产犊\预测算法\<最新版本>`，与训练器分开，加载训练器模型的拷贝），待产犊的牛有新数据即重新决策；“下载 → 决策 APP”查看。

# COWMATA Annotator 4.4.6（发布包 COWMATA-Pro-4.4.6）

## 1 所有业务文件都在一棵目录树里，按相对位置保存

现场的目录树（例如 `E:\`）：

```
1_下载器\扬大_高邮牧场\     原始数据 · 台账（下载镜像 + 上传\<账号> 工作副本）· 标注工程 · 科牧特_协作标注
2_标注器\<版本>\            本软件：安装包 · 便携包 · 源码包
常规经典算法\{3_训练器, 4_逆向决策器, 5_正向决策器}\产犊\<版本>\…
AI大模型算法\{3_训练器, 4_逆向决策器, 5_正向决策器}\产犊\<版本>\…
```

| 现象（4.4.5） | 根因 | 4.4.6 |
|---|---|---|
| 点“端侧数据下载”，数据下载到 `D:\COWMATA Pro 数据\下载数据`，台账到 `D:\COWMATA Pro 数据\现场台账` | 设置文件里保存的是“相对软件”的默认位置（`../COWMATA Pro 数据/…`）；目录树的牧场只在设置第一次生成时才被采用 | 默认就是目录树的牧场 `1_下载器\扬大_高邮牧场` 与其中的 `台账`；位置按“目录树内的相对位置”保存（`目录树/1_下载器/扬大_高邮牧场`）。旧默认位置自动改到目录树，原位置的文件在下一轮下载开始时移入（同内容去重，不同的保留并写明） |
| 上传（台账）的本地工作副本、台账同步的备份与记录在 `C:\Users\…\AppData` | 4.4.0 起放在 Windows 用户目录 | 移到 `台账\上传\<账号>` 与 `<牧场>\.edge-download\ledger-sync`，首次使用时整体搬入（未同步的修改一并保留） |
| 协作数据包默认在 `2_标注器\科牧特_协作标注` | 4.4.1 的约定 | 默认在牧场里：`<牧场>\科牧特_协作标注`（`2_标注器` 只放软件）；仍在旧位置的现场继续用旧位置 |
| 打开录像默认 `G:\`、ffmpeg / VLC 默认找 `F:\Applications` | 写死的盘符 | 对话框从目录树的牧场开始；工具先用软件自带的 `vendor`，再找任一磁盘的 `Applications` |

规则：

- **找目录树**：软件放在目录树里（便携包解压到 `2_标注器\<版本>\…`）就用这一棵；否则在本机各磁盘中找含 `1_下载器` 的最完整的一棵（顶层文件夹最多、版本最新）。
- **换盘 / 换电脑**：整棵目录树挪到别的盘或拷到别的电脑，设置无需修改；保存时写的是 `目录树/…`。
- **缺盘不改存**：设置指向目录树、但目录树所在的磁盘没插上时，下载停下并提示“找不到目录树”，绝不改写到 C 盘、D 盘等其他位置。
- 用户自己选择的目录树之外的文件夹仍按绝对路径保存（例如另一块数据盘）。

## 2 两条算法路线，按电脑选择随下载启动的正向决策器

- `常规经典算法` 与 `AI大模型算法` 各有 `3_训练器 / 4_逆向决策器 / 5_正向决策器`，版本文件夹在前（`产犊\<版本>\推理算法` / `前端对接`）。
- 下载设置新增 **随下载启动的正向决策器**（每台电脑分别勾选）：例如生产电脑只开常规经典算法，有显卡和本地大模型的电脑开 AI大模型算法。
- 风险等级总览、自动标注模型在 4.4.6、4.4.5、4.4.1 的布局中都能找到，取最新版本。

## 3 决策引擎：特征时段显著性与逐提前量自适应权重

- 每个特征按产犊开始前 0–1、1–2、2–3、3–6、6–12、12–24、24–48 小时与远离产犊（> 48 小时）的时段比较区分度（AUC）与稳健效应量；每个提前量只看它覆盖的时段，得出各特征的权重与方向，合成显著性分数 `salience@<h>h`（交叉验证中按牛交叉拟合）。
- **自适应**：每次训练先在台账牛上比较“加入 / 不加入显著性分数”（预警检出与误报；金标准牛只报告不参与），更好的才作为模型输入。本次（扬大_高邮牧场，149 次产犊）不加入更好：台账检出 94/107 对 92/107，因此显著性只用于解释与报告。
- 时段显著性写进模型清单：逆向决策器的 `训练决策全过程.html` 新增“特征时段显著性”热力图与逐提前量权重；监测报告显示“当前最关键的特征”；AI大模型算法用它挑选病例卡特征。本次数据中，产前 1–3 小时最显著的是尾根温度，12 小时为按昼夜节律校正后的温度。

## 4 风险等级与产程提示（参照兽医资料）

- 高风险（1/2/3 小时预警）：立即到场，之后每 15–30 分钟查看；中风险（6/12 小时预警）：移入产犊栏或加强巡栏，每 1–2 小时查看。
- 产犊中：每 15 分钟查看；**产程满 1 小时提示检查进展**（羊膜囊或胎蹄露出后 65–70 分钟仍无进展应检查胎位并助产，Schuenemann 等 2011），满 2 小时提示难产。

## 5 决策器输出可以点开

- `训练决策全过程.html`、`监测总览.html`、`监测报告\<牛号>.html`：指标卡、表格行、图表的任意小时、时间线事件都可点开明细；表格可排序、筛选、搜索；地址可直接定位（`#cow=<牛号>`、`#section=…`）；离线单文件，手机 WebView 可用。原有内容全部保留。
- 监测总览：顶部指标卡（全部 / 高风险 / 中风险 / 低风险 / 健康异常）点一下即筛选下方列表（键盘 Tab + 回车同样可用），与筛选按钮联动；列表表头点一下按该列排序，再点一下反向；搜索后列表不再退回旧样式。
- 训练决策全过程：表格排序修正——以前点表头会出脚本错误、把表头行排进数据，特征名（行标题）也被当成可排序的列；现在只有表头可排序，数字按数值大小排。
- 监测报告：“回到顶部”按钮修正（以前点了没有反应）。
- 出错提示中的示例位置改为目录树内（例如 `E:\2_标注器\派包`），不再示例 D 盘、F 盘。

## 6 现场反馈（4.4.4，10 月 2 日）与权限

| 反馈 | 根因 | 4.4.6 |
|---|---|---|
| 暂停后继续播放、或在九轴上点击定位后，九轴和视频不从真实位置继续，而是向后跳几秒再播 | 录像机（NVR）文件定位会落到之后的关键帧；播放中只要画面在“前方一段宽容窗口”内就算到位，并把共同时钟（九轴光标和所有视频）直接改成解码器时间。4× 时实测向后跳约 4 秒，1× 时则等到 12 秒超时 | 主视角在播放中定位：落点超过目标 0.3 秒即退到目标前 1/2/4 秒重新起播，追到目标（误差 −0.08～+0.3 秒）才开始走时；最多 3 次，之后按原规则兜底，不会卡住 |
| 同样的打标签操作，有的已确认、有的需复核 | 单击标签选中时手稍一抖（1 像素可能就是 1–2 秒），标签就被“拖动”了，边界被悄悄改动并退回需复核；另外重新“一次对齐”会把之前所有已确认标签退回需复核 | 拖动需超过系统拖动距离（至少 6 像素）才生效，单击只选中；重新对齐后，视频时刻变化不超过 1 帧（40 毫秒）的标签保持已确认，真正移动了的才需复核 |
| 只在素材面板点了一下九轴，标注工程 Motion 下就生成 `~标注.json` | 打开记录即保存整份工作状态（位置、设备身份、自动时钟） | 只有含人工工作的记录才写 `标注.json`：标签或草稿、人工对齐、人工核对牛号或数据类别、“完成本份”；只浏览不写，之前留下的空文件在再次打开该记录时删除；标签全部删除后文件随之删除 |
| 操作员不能“自动生成候选” | 权限表中候选生成（行为识别）、健康与繁殖、数据集构建只给管理员 | 操作员与管理员拥有全部业务功能，唯一区别是“账号管理”（用户与密钥）仍只有管理员可用。服务器上已部署的授权表无需升级：这三项随“标注”权限一起授予 |

台账上传器中的“删除选中”台账记录仍只限管理员：服务器（61.177.77.222）会拒绝操作员的删除，并使整次同步失败。如需开放，要先升级服务器接收端。

# 三类曲线与共享行为标签

主界面和历史复核使用九轴 Motion、PPG、温度 Temp 三个页签，共用时间范围、游标和一份行为标签。切页不会重读全部工程，也不会生成三份互相独立的标签。九轴分组仍提供 XYZ、加速度、角速度和磁场；温度使用摄氏度。

关联条件为同耳标、同完整设备号、同现场记号和相交的采集时间。历史 cow_id 中连写的耳标和现场记号按已有身份解析规则核对。数据采集时钟与录像人工校准保持分离；显示在同一时间轴不意味着设备时钟已得到外部校准。

曲线保留原采样率和缺口，不补零，不把无数据当负样本。旧版 Motion 内附温度及其提取副本的时间为区间中点估计，保留说明。PPG 缺少采样配置时不推造时间轴。温度只有一个采样点时显示单点。

行为标签由原标注记录拥有。训练扫描按采集时间投影到对应 Motion/PPG 记录，并保留共享事件身份与来源；修改源标签会使数据集指纹变化。原始 JSON 不受影响。不同来源的同一行为边界冲突、跨记录被裁剪的边界均标记待复核。点事件保持为点。传感器质量标记不跨模态复制。

配对数据集附带共享行为标签.json 派生快照，温度可按同一身份和时间区间引用。训练读取重新从当前标签派生，不把旧快照当可独立修改的真值。新的行为模型声明 cowmata-shared-labels-1 协议，导入时验证；历史未声明协议的模型仍按原方式读取。

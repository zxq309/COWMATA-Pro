# 端侧数据下载：使用与整合

该功能是下载器源码 `3090下载器/MotionDataVisualizer/src/MotionDownloadManager.cpp`、
`ServerRecordConverter.cpp` 和 SSH 启动脚本的 Python/PySide6 下载功能迁移。
仅迁移 Motion、PPG 原始数据下载，不包含旧下载器的可视化、分析、温度、报告或其他功能。

## 新版接入（仅两行）

1. 把 `cowmata_tailring/edge_download/` 整个目录复制到新版源码的同名位置。
2. 在新版主窗口已经创建“工具”菜单的地方加上：

```python
from cowmata_tailring.edge_download import install_menu
install_menu(self, tools)  # self 是 QMainWindow，tools 是“工具”QMenu
```

接入函数幂等，重复调用不会增加重复入口。子窗口延迟创建，启动标注工具时不查询网络。
当前 3.5.3 优化版源码已在 `cowmata_tailring/workspace/modern_window.py` 添加上述入口；
没有修改其他标注逻辑，也未替换另一任务正在处理的便携包或版本号。
不要用本包替换整个新版主窗口文件，只复制下载模块和添加入口即可。
运行依赖只有 Python 标准库与标注工具已有的 PySide6。打包时纳入该 Python 包；
若使用 PyInstaller 静态分析，可显式 `--collect-submodules cowmata_tailring.edge_download`。
主窗口应走正常 `close()`/窗口关闭流程；入口会在退出前停止线程，再恢复主窗口原有保存/退出流程。
若宿主使用 `QApplication.quit()` 强行绕过 closeEvent，应先关闭主窗口并等待下载线程结束。

## 使用

打开 **工具 → 端侧数据下载**。

- 选择或添加牧场：选择根目录，例如实际示范目录 `G:\扬大_高邮牧场`。
  其他牧场使用各自根目录；下载服务器、类别、对象、间隔和 SSH 参数分别保存。
- 选择类别：产犊、发情、正常、疫病，或怀孕下的孕早期/孕中期/孕晚期。
- 填写完整设备编号、牛耳标和现场记号，可添加多行。
  “从起始日期目录读取对象”只读取当前类别、起始日期下 Motion/PPG 的设备目录，
  不跨日期猜测设备绑定。跨日期换绑请分时段建立任务。
- 设备编号可空、牛号必填时，Motion 使用服务器的牛号查询，保留返回批次的实际历史设备；
  PPG 必须填写设备编号。记录历史牛号与填写牛号冲突时拒绝归档并记录失败。
- 现场记号可留空：优先复用同类别、同日、同设备、同牛号在 Motion/PPG 中唯一的现场记号；
  无已有记录时写为 `待核对`，有多个候选则报错。现场记号不跨日期推断。

三种模式：

| 模式 | 行为 |
| --- | --- |
| 手动 | 立即下载所选采集范围，执行一轮后结束 |
| 自动 | 立即执行；每轮结束后等待设定间隔，再查询从所选开始时刻到当前时刻的全部数据 |
| 定时 | 指定北京时间执行一次，下载所选采集范围；不自动改动采集范围 |

所有显示和目录日期使用北京时间，接口查询按原下载器约定转换成 UTC。
范围包含开始、不包含结束。自动模式重新查询整个范围以发现迟上传记录；已下载记录通过完成索引跳过。
较长范围会拆为一天一段，超过 10000 批的清单继续缩小时间段。
自动模式中的连接失败会在下一轮继续尝试，包括重新建立本任务的 SSH 隧道。
关闭子窗口会隐藏窗口并继续任务；“停止任务”取消下载或预约；退出主程序会停止。
取消网络请求需要等待当前阻塞读返回，通常不超过 10 秒；不强杀下载线程。
定时与自动仅在程序运行时生效；重启不会自行恢复任务，也不唤醒关机或睡眠电脑。

## 保存范式

```text
牧场根目录/
  产犊/                         # 或其他类别，怀孕/孕晚期等
    Motion/
      2026-08-17/
        546C50CA07FA-23077-E/
          2026-08-17_00-17-45.json
    PPG/
      2026-08-17/
        546C50CA07FA-23077-E/
          2026-08-17_00-17-45.json
  .edge-download/
    completed.sqlite3           # 本牧场下载完成索引，不是标注或行为数据
```

日期/文件名来自记录的毫秒 `create_time`。原始 Base64 数据不经分析或滤波；
外链 Motion BIN 校验后无损写回 `imu`；保留服务器其他元数据并删除临时 `url`。
校验 IMU v0/v1/v2 帧宽、PPG/ACC 长度，以及服务端提供的 SHA-256、大小与帧数。
同一秒、不同内容的记录会增加内容摘要后缀；临时写入完成后原子发布，绝不覆盖现有文件。
已有示范数据在相同目录及时间文件名前缀下会比较原始数据指纹，避免再存一份。
完成索引通过相对路径、大小和修改时间检查已下载文件，丢失或被修改则重新下载。
如果文件被外部修改但刻意保留相同大小和修改时间，索引无法发现这种修改。
删除下载索引只会导致重新核查与下载，不会删除 JSON。

## 服务器与 SSH

- 保留原 `/device/data/count`、`/device/data/motion`、`/device/data/pulse` 协议。
- `http://127.0.0.1:18031` 对应原 3090 SSH 隧道。**所给 3090 原始数据库接口只提供 Motion，
  不保存 PPG**；PPG 应选择原有提供 `pulseUids` 和 pulse 详情的设备服务器。
  客户端不能凭空补齐服务端没有的数据，清单未返回数据会在日志明确显示。
- 若需要程序建立隧道，勾选 SSH 并选择已有私钥。参数可改，默认沿用原脚本的主机和端口。
  只保存密钥路径，不复制密钥、不保存数据库密码；使用系统 OpenSSH 和已有 known_hosts。
  已有隧道时不勾选 SSH，直接使用本机接口地址即可。
- 程序仅终止自己创建的 SSH 子进程，不终止外部隧道。

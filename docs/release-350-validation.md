# 3.5.0 验证范围

## 源码与便携包

- 干净源码环境：913 项通过、11 项跳过；跳过项依赖发行包提供的二进制组件。
- Ruff 检查通过。
- 便携目录与 ZIP：12,017 个文件逐项 SHA-256 一致，未出现清单外文件；包括当前图文教程及配图。
- 隔离外部 Python/PATH、阻止 Python 网络访问：随包 Qt、VLC、FFmpeg、OCR、五个事件模型、历史标签及嵌入原始九轴读取通过。

## 打包后真实界面

在 Windows 本机、已归类时钟缓存、未清空系统文件缓存条件下，使用真实九轴与录像测试：

| 场景 | 波形出现 | 首路视频 | 全部视频 | 播放期间界面响应 P95 |
| --- | ---: | ---: | ---: | ---: |
| 单个视频配单个九轴，跨盘 | 0.274 秒 | 1.022 秒 | 1.023 秒 | 24.3 毫秒 |
| 单九轴配当日三路录像 | 0.255 秒 | 1.022 秒 | 1.589 秒 | 24.4 毫秒 |

三秒播放内各路持续产生画面，参考时钟前进；明确选择保存位置与保存后回看通过，原文件和原工程标签未改写。以上不是所有机器、所有录像或八路压力场景的性能保证，也不是模型效果评价。

安装器校验、实际安装/卸载与保留用户文件的结果，随 Release 的 `COWMATA-3.5.0-Delivery-Checks.json` 提供。源码、安装器和便携 ZIP 均提供下载校验值。PPG 仍为占位，不输出假波形或假模型结果。

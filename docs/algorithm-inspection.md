# 单视角算法检查

菜单顺序：文件 / 编辑 / 视图 / 工具 / 行为识别 / 健康与繁殖 / 帮助。

- **行为识别**：起立过程、卧倒过程、抬尾、甩尾、排尿、排便、爬跨、努责。前五类接入已注册的 20260906 版本；其余显示「待接入」，不会借用其他算法生成结果。
- **健康与繁殖**：发情、产犊、怀孕、疫病。当前均是单视角观察入口，算法未接入，不生成状态、风险或疾病诊断。
- 每个入口固定显示一个摄像头，从面板下拉切换；保持同一参考时刻，切换时等原片画面到位。不会解码隐藏视角预览；返回标注布局后恢复之前的布局和播放策略。
- 「运行算法」扫描当前完整九轴并后台运行。现有模型只支持完整 V2 记录，其他 JSON 可正常人工标注；分数不是概率，无输出不是负样本。
- 双击输出定位九轴及已校准录像。独立算法结果保存于工程的 `algorithm_inspections`，不自动进入人工标签、视频草稿或 `event_model_runs` 候选队列。
- 「选择对应人工标签」只切换标签类型。旧工程缺失标签时，询问后追加，不改旧标签索引；动作起止和真值仍由标注人员独立确认。
- 原候选标注入口保留在「工具 → 事件候选预测」。两个入口共享校验过的模型引擎及可替换缓存，但各自保存结果；同时只允许运行其中一个后台推理任务。

## 迭代算法

行为菜单通过稳定标签代码绑定 `assets/event_models/*/pack.json` 中的模型；新版本可沿用既有的 `csv-points-v1` 接口，经维护者审核、文件哈希注册和离线实测后打包。模型分数、输入格式和时间语义必须保持明确。

行为代码：`STANDING_UP`、`LYING_DOWN`、`TAIL_RAISED`、`TAIL_WAGGING`、`URINATION`、`DEFECATION`、`MOUNTING`、`STRAINING_BOUT`。

健康与繁殖不复用事件点接口冒充决策。未来接入需另行定义输入时间窗、输出含义、质量拒绝条件、真值来源和版本适配器，再启用按钮。当前不得宣称这些算法可用。

## 品牌与安装包

品牌配色来自 https://www.cowmata.com/en/ 与官网 CSS：主色 `#8ADD66`，辅色 `#35AFC8`，原始字标 / favicon 为 `#92C142` 系列。小图标直接复用官方 favicon，仅转换 Windows 尺寸，不重新设计公司标志。按钮使用深色文字以保证可读性；标签类别色保持稳定。

离线包保留两个私有 Python 环境、Qt Widgets/SVG、VLC、FFmpeg/ffprobe、OCR 和全部已接入模型。构建时仅排除无调用的 Qt WebEngine 及开发资料、调试符号和独立 ffplay 工具；不用系统安装的播放器补缺。独立块 LZMA 压缩避免整包临时解压，实际体积及安装时间以本版验收记录为准。

## 验证结果

- 新增 11 个回归用例，逐个先复现失败，再验证修复。保留既有测试，仅补全一处旧测试假对象的片段身份。
- 完整源码测试：**785 通过，5 跳过，0 失败**，74.30 秒。5 项是纯源码目录不含发布包二进制行为模型的检查，本轮未重新验证安装包或行为模型包。
- Ruff 全源码与测试检查通过；Git 差异检查无错误。
- Windows 实际 Qt 窗口与 VLC 硬件解码：打开 3 份演示九轴和 2 段本机牧场录像节选；1/2/4 倍速播放、往返切换记录、保存退出、预览点击切主视角均通过，已有标注保留。
- 加压实测曾抓到恢复播放瞬间 **262 ms** 的软件时钟通知偏差；补充回归并修复后，最终各倍率采样中九轴映射时间与播放器参考时间差均为 **0 ms**。这是软件内部时钟一致性，不等于相机与设备物理时钟已人工校准。VLC 时钟仍按自身约 0.37–0.45 秒的更新节奏报告，未用猜测时钟代替解码时间。
- 原生 Windows 滚动条连续拖动位置：103 → 206 → 309 → 412。布局使用 8 个槽位，其中 2 个有实片、6 个仅用于布局压力验证，不代表 8 路真实录像同时播放。
- 真实 FFmpeg/OCR 后台检索：主视角持续播放时，未索引的另一视角完成首次时间识别和完整索引，加入播放列表。约 48.96 秒，界面心跳最大间隔 0.224 秒。首次 OCR 仍需时间，不能据此承诺所有录像秒开。

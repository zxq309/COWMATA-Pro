# 3.9.1 端侧下载修复（2026-09-16）

打开“数据准备 → 端侧数据下载”后，先选择手动、自动或定时，检查保存位置、时间范围和数据类型，再点“按所选方式启动”。打开窗口、重新打开程序、切换模式和保存设置都不会自动下载。

- 手动：执行一轮。
- 自动：点击启动后立即执行一轮，随后按所设分钟间隔检查。
- 定时：点击启动后等待指定的北京时间，到点执行一轮；需保持 Pro 运行。
- “停止 / 取消定时”会取消已启用的计划；退出 Pro 后计划不自动恢复。

默认选择 Motion 与 PPG，温度可自行勾选。下载前先核对所选牧场根目录下各分类中的已有原始文件；以数据类型、完整设备号和服务器 UID 识别已存在记录，已有 Motion 不会误挡缺失 PPG。旧文件即使已移动到其他分类，仍保持原位，不因 CSV 修改重新复制。没有 UID 的旧文件在取得详情后按传感器内容核对，后续使用本地缓存。第一次建立本地索引可能需要较长时间，日志会显示进度。

新文件路径保持：

    牧场根目录/分类/Motion或PPG/YYYY-MM-DD/设备号-耳标-现场标记/YYYY-MM-DD_HH-MM-SS.json

没有现场标记时省略该段。文件名不加毫秒、UID或哈希；原始 JSON 不添加由下载器推算的牛号或分类字段。同秒存在不同内容时提示冲突并保留原件；损坏文件在补齐前先保存原字节到 .edge-download/recovery。不会批量改名、移动或删除你整理好的文件。

分类优先保留上传器 CSV 的明确“数据分类”（含待核对）；空白或未分类时按上传器 1.3.1 的“监测目的”映射。样本试验台账的精确佩戴时段优先于设备台账；无法匹配的分类或时段保留为未分类/待核对，不推测设备或牛号。

刷新服务器 CSV 时，使用上传器 1.3.1 的账号、密码登录台账服务器。账号会话只保存在本次运行的内存中；需要的 SSH 授权文件仍由原连接设置指定。若直接使用已同步到本地的三份 CSV，可取消“每轮先从服务器刷新三个 CSV”。下载器只读取服务器台账，不提交台账修改。

验收：116 项相关回归测试通过；与 E:/zxq/1.3.1 源码核对了三份 CSV 完整表头和全部监测目的映射；抽查截图中的 4 个 Motion 原件及 1 个 PPG 文件，UID 识别成功，SHA-256 未变。

本机 CSV 解析得到 129 台设备、776 段佩戴记录，另有 26 条核对项：设备号位数异常、拆除时间填写“新硅胶垫”、生产时间填写“死胎”等。设备台账本身没有监测目的，下载时在对应时段优先匹配样本台账；没有匹配的记录仍显示未分类。

未执行实际服务器登录或批量下载：登录会话及传输链使用隔离测试验证；真实同步需在界面登录后由使用者启动。原始数据目录未作更改。

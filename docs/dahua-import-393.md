# 3.9.3 原始录像准备与播放

数据准备 → 数据归类分为常规归类与原始录像转码两个页签。后者使用独立任务目录，保留原始录像，输出可播放 MP4。扫描不会自动决定相机视角；请查看静态缩略图，人工将来源映射到固定视角01–20。空视角保留编号，不生成空视频。

支持具有 DHAV 包和时间信息的 DAV/DHAV 文件，以及已实测的 DHFS4.1、2 MiB 分片录像机磁盘。扩展名为 h264/h265 的文件仍须具有可验证的 DHAV 包；不含时间的纯裸码流不能推测拍摄时间。未知布局、断链、越界或异常 PTS 会记录待核对，不扫描已删除录像，不格式化或写入原盘。

北京时间范围按实际码流时间截取，可按午夜拆分。转换保留原分辨率，输出 H.264 8 bit / AAC MP4，完成后全片解码检查。支持以已有 Motion 为基准补视频，以及一并接入 Motion、PPG、Temp JSON。来源摘要、视角映射与处理问题写入归类附属文件。

任务在后台运行，限制进程资源并与常规归类共享并发额度。暂停后保留完成片段；恢复会重新检查来源身份和输出哈希。同名同内容复用，同名不同内容保留另一份并使用碰撞编号。

视角表格按当前字体与缩放设置紧凑行高，静态缩略图可点开大图。主标注界面仅加载归类后的 MP4；20 路分为 01–08、09–16、17–20 三组，同时最多显示 8 路。切组保留时间、播放状态及当前标签。

## 已核验文件名优先

符合 YYYY-MM-DD_HH-MM-SS.mp4 的文件直接使用名称中的相机日历时间；允许归类碰撞后缀 __001。日期与时间须合法，时区采用工程既有的相机日历约定。只读取媒体头中的视频时长，不重复抽帧、OCR 或扫描全片数据包。后台内容身份检查仍保留。

不符合标准命名的文件继续使用原有原生时间/OCR 核验流程。已保存人工时间校准优先；人工框选 ROI 核验仍可主动执行。相同内容若位于不同时间名或视角路径，时间与视角分别绑定到当前路径，避免缓存串用。

文件名快速路径按用户已验证归类结果的约定工作；它不是对录像机时钟准确性的新增测量。相机与传感器的人工同步规则仍保留。

历史牧场文件存在扩展名为 MP4、内部实际为 MPEG-PS 的情况。此类文件仍以规范文件名作为起始时间；首次需要建立播放时长索引并缓存，不调用 OCR。若数据包时间不连续，则保留待核对状态。实测三份 256 MiB 文件首次约 3.2–7.6 秒，属于背景索引耗时，不能承诺所有文件瞬时打开。

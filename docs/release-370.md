# COWMATA Annotator 3.7.0

3.7 将数据集构建改为五个独立任务：行为识别、产犊预测、发情预测、怀孕监测、疫病监测。每次导出新建时间戳版本，按行为、Motion/PPG、Raw/Label 配对保存原始 JSON 和标签。

- 文件名采用 `设备-耳标-现场标记_日期_时分秒_raw.json` 与同名前缀的 `_label.json`。原始数据逐字节复制并校验；未标注记录明确列为 Unlabeled/Context，不编造标签或阴性样本。历史采食记录单独保留，无新快捷键。
- 产犊预测导出起立过程、卧倒过程、努责、胎儿首个部位首次可见、犊牛完全娩出五类；其他预测任务按已知来源类别整理，文件夹类别不代表临床结论。
- 支持暂停、继续、已完成配对复用、实时统计和 CSV。来源或标签在暂停后变化时，新建版本，保留既有版本及人工修订。
- 复核支持打开原始 Motion/PPG、既有标签和数据集 Raw/Label 对；核验身份后显示信号和可用的匹配录像。修改标签类别、边界、备注后写回原标签，保持记录编号并保留修订备份。复核不新建标签记录、不改写原始传感器样本。
- 新增批量改标签和批量删除，可撤销；点事件与区间不直接批量互换。
- 标签快捷键更新为 1–9、A–F。站立、躺卧、行走、敲击从新标签配置移除。旧尾部标签按来源迁移；仍有使用记录的努责首次出现不会静默删除。
- 多视角网格按可用画面面积布局；角速度 X/Y/Z 分行展示，PPG 光学通道独立展示。
- 数据归类独立调度各视角；重型解码/OCR 共享 1–2 个槽位，复制共享 2–3 个槽位，随可用内存收缩。Windows 后台进程应用较低优先级、CPU 亲和性与 35% Job CPU 上限（系统支持时），缓存有界；界面每秒合并进度，避免逐块重建整表。
- 保留 3.6.3/3.6.4 的端侧下载集成、归类断点复用、独立实时记录窗口与离线直接启动；GitHub 更新检查失败不阻止进入软件。

## 安装与使用

完整解压便携包后运行 `COWMATA.exe`，或使用 Setup 安装包。源码包供开发者使用，需要按 README 安装依赖。便携包包含离线运行环境、播放器与 OCR 模型，不包含用户数据、日志、账号或个人配置。

详细步骤见 [3.7 操作指南](operator-guide-370.html)。Excel/WPS 打开的 CSV 是当前快照；需要自动刷新时使用软件的实时记录窗口。文件被外部程序锁住时，持续写入可用的实时 CSV，窗口显示最新记录。

PPG 回看需要记录中的采样配置/有效时长及可匹配的原始数据。录像缺失或同步未确认时，显示明确状态，不编造对应关系。自动模型只提供候选；旧抬尾/甩尾模型不能识别站立或躺卧，必须根据录像选择姿势。

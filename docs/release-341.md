# COWMATA 3.4.1

选择倍速或行为后，空格现在直接控制播放/暂停；文本输入框和已打开的下拉列表保留输入行为。起点与终点相同的区间不会创建，当前起点保留，可继续播放后结束；点事件仍可记录。

新完成的标注自动选中并滚动到可见位置。单击列表会同步选中波形上的左右手柄；标签轨道支持拖动两端改起止、拖动中间整体平移。边界修改后保留待复核状态；单击而未拖动不改变确认状态。编辑框也会拦截零时长区间。

行为识别面板的“选择对应人工标签”增加常驻操作步骤，点击后立即更新动作按钮。它只选择人工行为类型；用户仍需观察视频、记录起止并回看确认，不会将算法结果自动写成人工标签。

包含 3.4 的数据整理规则：五类批次、实际采集日期、视角01～08、规范设备/耳标/现场标记、PPG 占位、跨日加载、同盘移动与跨盘校验复制。视频命名只保留起始秒 YYYY-MM-DD_HH-MM-SS，流内时间优先，OCR 失败时仍采用可读流内时间；复核状态保留在索引中。

随包图文教程已更新，新增上述操作的实际 Windows 窗口截图。演示画面、九轴与标签使用隔离的生成数据，不作研究真值。

验证：833 项完整回归通过、3 项跳过；仓库 CI 范围静态检查通过。新增交互测试先复现失败再验证修复。真实 Windows 窗口已实测空格播放/暂停、零时长拦截、最新标签选中、拖动保存、提示及导出后历史读取。详见 release-341-validation.md。

# 牧场目录输出与保留约定

牧场目录只承载正式素材、人工标注、索引和恢复所需状态。开发检查报告、测试素材、截图和打包中间件应放在牧场目录之外。

- 下载：健康类别下保存 Motion、PPG、Temp；.edge-download 保存增量下载台账、来源与恢复状态。工程扫描和数据集构建跳过整个 .edge-download，不能把隔离副本作为新素材重复纳入。
- 牧场标识：.cowmata-farm.json 是共享录像目录与协作包匹配的身份文件，不是传感器 JSON，不能作为素材索引或删除。
- 常规归类：同盘移动、跨盘复制及原有并行策略保留。未完成的 .partial 用于恢复；成功提交的当前片段进入正式路径。历史任务暂存不能仅因扩展名而批量清理。
- 原始录像：大文件暂存使用目标盘任务缓存；片段验证后归档，派生媒体按已有任务逻辑释放。任务清单、运行记录和归档凭据需保留，不能把运行中的缓存当成废料。
- 旧标签迁移：保留原始 JSON、人工标签、资源索引与迁移凭据；不再写 PPG 占位说明文本。既有文本须经过用户确认才能删除。
- 标注与复核：标注工程、标签、索引、恢复备份和锁文件属于工作状态。不能根据文件小、隐藏或扩展名为 .bak/.lock 判为垃圾。
- 多人协作：派包、回包及收包审计记录为用户交付物；ZIP 生成的私有临时文件在成功或失败后由其创建流程清理，接收事务保留冲突和回滚证据。
- 数据集、模型、预测：用户选择目录中的版本、Raw/Label、模型清单、评估、识别与预测报告都是可追溯结果；不能自动删除旧版本或人工复核历史。构建未完成时保留恢复暂存。
- 空目录：类别根目录、跨日覆盖和视角占位可能服务现有逻辑，不按“空”一刀切删除。
- 历史清理：列出相对路径、字节数、保留副本及内容哈希。经用户确认后，执行前重新检查目录边界、文件身份、标注依赖和活跃任务；有变化则跳过。审计报告写到牧场以外。

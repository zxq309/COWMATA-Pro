# COWMATA Pro 3.8.4：端侧下载与现场记录

基于 3.8.3 源码继续开发，保留一次对齐和原有标注功能。本次仅提供便携解压目录和源码 ZIP。

## 使用

1. 双击便携目录中的 COWMATA.exe，进入“数据准备 → 端侧数据下载”。
2. 检查“九轴数据保存位置”和“本地现场记录位置”。首次使用会读取本机独立下载器的服务器地址、九轴保存根、补齐起点及间隔；使用独立的 Pro 配置保存后续修改。
3. 点击“检测两个连接”，或点击“一键下载 / 立即同步”。也可单独点击“仅刷新三个 CSV”。
4. 默认每 15 分钟检查；起点固定保留，能补下迟上传数据。在 Pro 运行期间可保持自动同步，关闭下载子窗口仍继续，退出 Pro 会等待请求停止。

## 三个固定 CSV

- 样本试验台账.csv
- 扬大产犊登记汇总.csv
- 扬大测试设备台账.csv

本地默认：F:\牛舍\_现场记录。
服务器默认：F:\牛舍_现场记录。这是提供的上传器 1.1.0 和真实服务器确认的固定目录，与本地路径分开设置；修改客户端文字不会迁移服务器接收端的白名单目录。

使用上传器 1.1.0 的 cowmata-ledger-upload-v2 协议，操作为 pull，提交变更始终为空。每轮先读取并校验三个 CSV 的表头、记录 ID、行数和 SHA-256，再按原始字节写入本地固定文件。内容相同不重复改写；原有文件被替换前备份到现场记录目录的 .edge-download/csv-backups/，不清理历史备份。

某文件下载或校验失败时不开始替换三个 CSV。CSV 正被编辑或写入失败时报告错误并保留/恢复旧文件，下轮可继续。仅将读取台账作为分类依据：样本试验台账按完整设备号、历史牛号、佩戴时段和明确的数据分类对应；重叠或待核对记录保留待核对状态。设备表的短编号不会推断为完整设备号；产犊登记不会自动充当九轴佩戴记录。

## 服务器连接

台账默认使用 61.177.77.222:8022、cowmata_upload。复用已安装“COWMATA 现场台账”的 auth/upload_key，仅记录已有文件路径。与上传器相同，连接绑定真实网卡，SSH 绕过代理并严格验证服务器主机密钥。随包提供同版 SSH 组件和公开主机密钥。

九轴可选两种方式：

- 默认复用已测通下载器的 http://127.0.0.1:18031 及 CowmataRawDownloadTunnel-18031 已授权任务。
- 在“服务器连接设置”中选择“真实网卡直连 SSH”，填写已有九轴 SSH 用户和私钥，远端接口默认 8031。直连使用与台账相同的公网服务器和 SSH 端口，通过独立权限建立端口转发。台账上传账户的受限私钥不提供九轴转发权限。

程序分别显示台账和九轴连接结果。缺少九轴授权时，三个 CSV 仍可独立刷新。授权文件不包含在便携包或源码包中；换机需配置该机自己的已有授权。

## 九轴数据

沿用所提供独立下载器的固定快照分页、历史身份校验、迟到批次复查、损坏文件补下及可恢复重复回收规则。数据路径为：

九轴保存根 / 类别 / Motion / 日期 / 完整设备号-牛号-耳标 / 采集时间.json

未匹配台账时保留“未分类”。支持怀孕各孕期目录。CSV 修订后重新核对当前管理的数据分类，JSON 原始字节保持不变。PPG/温度保留在“按设备下载 PPG / 温度”入口；3090 自动枚举仅提供九轴。

## 验证范围

- 本地 HTTP 模拟服务：分页、重复下载、迟上传、待补齐转可下载、损坏文件补下。
- CSV：上传器三套精确表头、校验错误、取消、网络失败、同步期间本地编辑、替换失败恢复、无变化不改写。
- 分类：完整身份和时间匹配、重叠待核对、删除记录、孕晚期到正常的目录修订，原始 JSON 字节一致。
- Qt：设置保存、停止后再开始、宿主退出等待后台线程；回归原下载功能和一次对齐。
- 本机真实台账服务器：三个表分别读取 383、281、439 条；连续两轮更新数为 3、0，校验通过。测试副本保存在独立 QA 目录。
- 本机缺少已授权九轴任务和私钥，九轴真实服务器传输尚未验证；其协议和异常恢复通过本地模拟服务验证，直连路由和 SSH 生命周期通过隔离测试。

## 源码与构建

源码包含端侧下载改动、测试、SSH 依赖及原有 Pro 源码；不含个人配置、私钥或真实现场 CSV。

开发环境安装 requirements.txt 及 pytest 后执行：

    python -m pytest tests/test_edge_download.py tests/test_edge_download_384.py tests/test_single_point_alignment.py

复用本次便携包的 runtime、model_runtime_20260906、vendor 和模型文件进行离线构建：

    python scripts/build_portable.py --out 新的便携目录 --no-zip --components 本次便携目录

源码启动：python portable_start.py。便携用户无需安装 Python。没有生成安装包，也没有发布 GitHub 更新。

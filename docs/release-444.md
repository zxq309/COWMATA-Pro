# COWMATA Annotator 4.4.4（发布包 COWMATA-Pro-4.4.4）

## 4.4.3 问题清单逐条核对

| # | 反馈 | 改法是否合理 | 4.4.4 |
|---|------|------------|-------|
| 1 | 流程可优化：证据截图没必要，“补充证据”“确认真值”影响效率；建议改为 标签开始 → 标签结束 → 本次标注结束 | 合理。复核看录像本身即可，截图不参与训练；开始/结束时屏幕上的原片画面已经是可追溯的证据。只保留一条安全底线：九轴与录像没有对齐、或录像时间未核验时，不能凭空生成真值 | 标签结束即自动确认为真值，不截图、不再点确认；条件不满足时留成草稿并写明原因；截图移到“工具 → 旧版兼容” |
| 2 | 视频播完但九轴没完时不会自动切到下一个视频，提示“本视角仍有录像未索引…”，要往后点一下九轴才切换 | 合理，属于缺陷：下一段录像没提前建索引，且播放器遇到无画面就停 | 提前为下一段建索引；短间隔自动跳过；下一段在索引中时等待并自动继续；只有长时间无录像才停并说明 |
| 3 | 点九轴时“当前记录用到的录像”不是九轴开始时间所在的视频，提示“主视角到达录像缺口，已暂停” | 合理，属于缺陷。根因：录像机中途断流重连（流内时间归零），4.4.3 把这类录像算短，形成假的录像缺口 | 按录像机时钟分段定位，录像覆盖完整，开始时刻落在正确的录像上；已建工程自动重建一次索引 |
| 4 | 核验时读取结尾画面提示“无法解码所选位置真实画面”，怀疑视频损坏（开头有画面，中间和结尾没有） | 现象属实，但录像并未损坏，与问题 3 同一根因；另有一处毫秒取整会跳过最后一帧 | 重连后的任意位置可精确取帧；最后一帧可读取 |

## 1 标注流程：标签开始 → 标签结束 → 完成
- 标签结束时直接确认为九轴真值。开始和结束时屏幕上的原片画面（视频资产、帧位置、时间核验版本、相机校准版本）自动作为证据，与以前点“确认真值”时记录的内容相同。
- 一次 Ctrl+Z 撤销整条标签；需要改动时选中后“编辑”或“删除”。
- 自动确认条件不满足时留成“视频草稿 · 九轴待确认”，提示直接写明原因：本份未做一次对齐 / 某视角某录像时间未核验（可一键去核验）/ 牛号未确认 / 画面未到位。处理后双击草稿、点“确认真值”。建议每份记录先做一次对齐再标注。
- 跨两份九轴记录的动作：另一份里的部分在打开那份记录时自动确认。
- “确认真值”不再自动弹出证据截图；“补充证据”“证据截图”从标注操作中移除。证据截图保留在 工具 → 旧版兼容 → 证据截图（可选）…，以前保存的证据图仍可查看。
- 训练导出规则不变：只导出已确认真值，未确认、未看过的样本不当作负样本。

## 2 播放自动接下一段录像
- 两段之间几秒的间隔（换文件、录像机断流重连）自动跳过，并提示中断了多少秒。
- 下一段尚未建立索引时暂停并优先索引它，画面到位后自动继续播放；超过 2 分钟仍未就绪才停止等待并提示原因。
- 播放中提前约 1 分钟（随倍速放大）为下一段建立索引；这个请求不会打断正在进行的索引。
- 只有确实长时间没有录像时才停止，提示“此后约 N 分钟没有已索引的录像”及下一段开始时间，可点“下一录像时段”。“单路优先”模式同样适用。

## 3、4 录像机中途断流重连
- 部分录像机在一段录像中途断流重连时，流内时间（PTS）从 0 重新开始（高邮牧场视角02 约每 17 分钟一次，每次缺约 12.6 秒），但录像机逐帧自带的时钟是连续的。
- 4.4.3 遇到这种情况就放弃录像机时钟，改用数据包时间轴，把录像算短：例如视角02 的 2026-09-06_13-09-06 只算到 13:21:39（实际到 13:32:30），于是 13:27:40 开始的九轴记录前几分钟“没有录像”；重连后的位置被定位到错误的文件偏移，读取结尾画面失败。
- 4.4.4 在每次重连处分段，每段按录像机时钟定位，真实的 12.6 秒缺口保留为缺口；取帧和播放时把分段时间改写为连续时间，任意位置都能精确取帧。
- 验证：高邮牧场 2026-09-06 13 点前后 16 段录像（视角02–07，只读）：没有重连的 11 段索引结果与 4.4.3 完全相同；4.4.3 拒绝的 5 段重连录像现在完整可用（如 13-09-06 共 23 分 12 秒、2 段；13-32-30 共 22 分 47 秒、3 段）。自动测试用真实 H.264 合成重连录像，逐帧核对重连前后取到的画面与原始编码帧一致。
- 已建立的工程首次用 4.4.4 打开时，自动为受影响的录像重建一次索引，人工标注和核验读数保留。与录像机时钟一致的人工读数不再把整段降级为“待复核”；人工读数不会跨过重连缺口外推。
- 导出标准 MP4 只处理连续录像；中途重连的录像会说明原因，原始录像可直接标注。

# COWMATA Pro 3.9.5

- 端侧下载每轮重新核对三份台账。产犊开始、产犊结束、九轴、脉搏、温度均已填写，且九轴与温度均有效，才下载 Motion、PPG、Temp；设备台账不能单独授权全量下载。
- 非产犊监测的“/”视为已填写；产犊监测必须有有效且先后正确的开始、结束时间。缺项或身份时段冲突暂不下载，后续补全会再次核对。按监测目的分类。
- 下载预览在后台读取，按可下载、待补全、不下载展示原因。服务器台账刷新失败时不使用旧表继续下载。
- 常规归类可一次粘贴多个视频总目录，后台逐步显示视角。所有目录共用有限数量的处理任务；修复全选、进度更新和暂停恢复时重复遍历大量路径造成的停顿。
- 常规归类与原始转码均支持视角01–20的规范归档。主标注画面继续最多同时显示8路，通过分组翻看。
- 正常视频先做有界的可见内容检查，疑似黑屏或损坏再完整核验。复制仍校验源文件与目标文件 SHA-256。同盘移动继续使用已有安全移动流程。
- 从片段起点转换、编码兼容的 H.264 原始录像可保留视频码流封装为 MP4；中段精确裁切及不兼容 HEVC/全范围像素继续转码，输出仍校验时间轴与解码。
- 事件1、2、7、9、A接入行为模型、数据集训练和自动候选。9、A为实验性传感器候选定位，界面明确要求回看视频确认，不代替视觉事件判定；时间待复核的标签不进入正例训练。
- 延续独立温度、三类曲线共享标签、时间戳视频优先加载、录制盘只读选择及保存退出更新逻辑。

- 新增统一账号与权限：管理员使用账号、密码登录；操作员首次使用账号、密码、一次性授权码，本机激活后可用账号密码登录。保存密码、自动登录默认关闭；显式勾选后按所选方式登录，保存密码使用 Windows DPAPI 加密。管理员维护三列账号表，删除账号后撤销访问。
- 修复画中画移动后曲线残影，以及分层标注目录中历史证据图片的定位。
- 帮助菜单新增 3.9.5 离线图文教程，覆盖 36 个操作主题、完整菜单与角色说明，支持搜索、图片放大及打印。
- 文件夹产犊分析分别显示采样窗口与预测可用时刻；整包收到后才使用 Motion、PPG、Temp，历史基线也排除未到达记录。旧口径决策模型须重建证据并重训；演示性回顾训练不代表预警效果已验证。
- 减少批量分析进度的频繁写盘，保留阶段切换与完成状态，改善多日 JSON 分析速度。

启动需要联网核验账号。管理员密码变更会使旧设备授权失效，需用新密码重新登录。发布包包含受限的连接组件，不包含管理员密码、真实账号表、客户数据或业务训练模型。

性能取决于总字节数、磁盘、视频编码及是否需要转码。2000个文件8小时不是无条件保证，应按本机实测和样本时长估算。升级前请先暂停并保存正在执行的任务。

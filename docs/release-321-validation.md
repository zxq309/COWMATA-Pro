# 3.2.1 操作补充与验证记录

日期：2026-09-09。本地交付版本，不代表已经发布到 GitHub。原 3.2.0 保留；新源码与离线软件放在独立的 COWMATA_3.2.1_纯净新版 文件夹。

## 本次问题与修复

这批数据有 366 份九轴、842 段录像，录像合计约 210.5 GiB。录像按“数据工程/视角01_海康、视角02_神眸、视角03_神眸/批次”组织。

旧版以顶层目录、分辨率、时间戳位置组合视角名称，造成三台设备混组，分辨率变化又拆组；保存的视角还可能不覆盖当前九轴。另一个瓶颈是先读取大量录像时间提示，再准备可播放片段。不是用户按钮点错。

新版使用明确的视角目录分组，保留人工命名与已有校准，按九轴时段优先检索匹配片段。有画面覆盖时自动选中主视角，原先手动取消勾选的选择仍被尊重。成功提示以九轴和实际原片帧就绪为准；纯九轴工程以九轴就绪为准。只读/时间待复核等原有提醒继续显示。

“加载记录…”窗口保留最近 500 条完整状态，可拉大、选择和复制。加载中退出使用可取消的后台任务。只有本次未成功的新工程自动生成的索引、预览等可清理；已有工程、人工标签、证据及无法确定归属的文件保留。进程被系统直接终止时无法即时执行清理；下次打开通过未完成加载标记恢复处理。不会自动删除当前数据资源里的旧工程成果。

## 播放与定位

每路画面下方常驻进度条和本段经过时间/总时长。点击定位，拖动松开提交最终位置，避免堆积中间跳转。共同时间轴联动时，九轴与其他视角同步到参考时间。

1×、2×、4×由主视角实际解码时钟驱动，减少反复追赶导致的卡顿。对本批原始监控 PS 封装，首次播放按需生成当前片段的无重编码封装缓存，并校验时间轴；缓存有独立零基准时间，不复用原文件字节偏移。只缓存工作片段，总上限 8 GiB，旧缓存可淘汰。暂停精确标注仍直接从原录像提取画面，原数据、帧率与科研时间证据不被改写。

## 续标、保存和改错

| 显示 | 含义 |
| --- | --- |
| 蓝色 ▶ 正在标注 | 当前记录，尚未确认整份完成 |
| 橙色 ● 未完成 | 已开始，切走后保留标签和位置 |
| 灰色 ○ 未开始 | 还未开始人工处理 |
| 绿色 ✓ 已完成 | 用户明确确认完成；仍可重新打开修改 |

切换记录自动保存；再选回时恢复上次位置。重新打开优先恢复选中的未完成记录，无可恢复记录时先选其他未完成，再选未开始。标了几条不会自动算整份完成。

点击“完成本份…”或 Ctrl+Enter，弹窗提醒保存，可选择保存并完成后下一份、完成后保存退出、未完成暂存退出或继续本份。录像联动到当前九轴末尾时也提醒确认。关闭主窗口时选择保存并退出、不保存本次改动并退出或返回继续标注。加载尚未成功且没有人工成果时直接取消加载和清理。

自动保存每 5 秒检查改动，切换或编辑时也会保存。“不保存本次改动”不撤销此前自动保存。保存失败会保留窗口及内存成果并提示，不能悄悄丢失标签后退出。

改错步骤：主窗口打开原数据工程 → 左侧选原九轴 → 下方标注列表选一条 → “编辑”修改标签类别、起止秒和备注，或“删除”。双击条目回看对应位置。修改自动保存，原完成状态恢复为未完成，改过的确认标签转为待复核；删除可撤销。独立的“历史标注回看”窗口继续只读，修改要在主工程进行。

## 本机验证

Windows，NVIDIA GeForce RTX 2080 Ti，软件私有 Python 3.13.15、PySide6 6.11.2。实际读取用户指定的上述数据，测试索引与缓存放在工程之外；没有改写原录像、九轴、已有标注工程。计时从执行相应操作开始，包含真正画面就绪，不以按钮响应冒充视频就绪。

| 操作 | 实测结果 |
| --- | --- |
| 旧版首次打开同一批数据 | 九轴 0.82 秒；65 秒内未自动出现首帧 |
| 新版首次打开，测试索引为空 | 九轴 0.77 秒；首帧 10.83 秒；成功提示 10.99 秒 |
| 新版读取已有索引的隔离副本 | 九轴 1.22 秒；首帧 1.52 秒 |
| 加载第 3 秒主动关闭 | 关闭回调约 3 ms；后台结束约 0.13 秒；临时工程已清理 |
| 成功加载后关闭 | 关闭回调约 1 ms；保存及结束约 0.71 秒 |
| 三路原录像暂停定位至本段 80% | 0.18–0.49 秒 |
| 三路暂停定位至本段 10% | 0.19–0.25 秒 |
| 连续五次快速定位，以最后目标为准 | 最后请求后 0.44–0.51 秒 |
| 三路正在播放时远跳 | 0.12–0.14 秒 |
| 当前片段首次准备播放，含缓存生成 | 1.69–2.00 秒 |
| 已有缓存的播放启动 | 0.69–1.12 秒 |
| 三路分别测试 1×/2×/4×，各 9 秒 | 实际 0.963–0.974× / 1.952–1.985× / 3.937–4.017×，画面持续更新，主路无自行纠偏跳转 |

关闭性能计时不含用户在保存弹窗中思考的时间。播放实测每次一路，三台相机各选一段真实录像，不是三路同时 4×。结果是本机样本值，不保证全部 842 段、其他硬盘或其他显卡相同；首次定位未索引时段仍可能需要额外检索。尚未独立视觉核准的时间仍提示待复核，播放流畅不等同科研真值已确认。

最终回归：549 项通过、5 项因可选环境跳过。覆盖失败/取消加载清理、人工作业保留、缺省视角、响应式关闭、三个退出选择、颜色与位置恢复、重新打开后编辑/删除/撤销、倍速时钟、滑条提交、封装时间轴隔离及现有科研证据保护。离线软件另执行运行库、OCR、历史导出与安装文件校验；详细结果随本地验证摘要交付。

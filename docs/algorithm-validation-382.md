## 规律复核

本次重新计算全部243份有标签记录的特征规律。
可用事件中，约89.91%的卧倒和80.00%的起立具有至少10度的姿态变化；努责约4.57%。
因此三类独立建模，保留努责区间，不将同一幅值门槛套用所有事件。
比例仅描述当前可用样本；缺少有效信号的事件未纳入该比例的分母。
15项牛号冲突在问题表保留，冲突记录的个体产犊事件不用于个体分析。

# COWMATA Annotator 4.4.7（发布包 COWMATA-Pro-4.4.7）

## 1 本机大模型：统一入口与推理身份（与本机服务配置对齐）

本机千问 Qwen3.8-27B 的服务已统一为 **LiteLLM 统一入口（`http://127.0.0.1:8100`）托管请求、llama.cpp 执行推理**，原 Ollama 引擎停用（旧 Ollama 协议由兼容入口转发，不另加载模型）：

| 档位 | 权重 | 显卡 | 并发槽 / 上下文池 | 用途 |
|---|---|---|---|---|
| light | Q4（与原 `qwen3.8:27b` 同一权重） | GPU0 | 2 / 32K | **产犊正式模型**（固定） |
| pro | Q6_K | GPU1 | 6 / 32K | 研究候选；局域网默认 `qwen3.8:27b` |
| sft | 编程微调 Q4（非产犊数据） | GPU0 | 3 / 16K | 研究候选 |
| max | UD-Q8 | 双卡 | 待 Windows 重启后验收 | 暂停 |

AI大模型算法 全部改走统一入口：

- **推理身份**：训练时记录权重文件、llama.cpp 版本、对话模板、并发槽与上下文；回溯与实时推理每批都核对，与训练时一致才出结果，不一致时提示“先重新训练”，绝不把别的模型的概率当成本模型的结果。
- **候选与推广**：训练先写独立的时间戳候选版本（`训练候选\…`），校准、误报预算、真实正向烟测全部通过后才把模型、评估与选择文件事务推广为正式版本；任何一步失败都保留原正式模型。
- **共享缓存**：推理结果按“完整请求 + 推理身份”缓存，训练与模型对比共用，中断后接着算，同一问题不会问两次。
- **模型对比**（3_训练器 `模型对比.bat`）：在同一批金标准留出小时上，对比本机各模型（light / pro / sft）× 推理方式（数值法 / 分档法）、不用大模型的检索基线、常规经典算法与当前正式模型；AUC 附按牛自助抽样 95% 区间与配对差值，并走 4_逆向决策器 同一套预警与风险等级打分。分档法：模型只答一个字母（距开始产犊 A=1 小时内 … H=48 小时以上），取它给各字母的概率累加成 1/2/3/6/12 小时内的概率，比让模型写数字快 3–10 倍。
- **修正**：预警阈值改在最终单调概率上选定（与导出给逆向回溯的概率一致）；满足不了误报预算的提前量明确“停用预警”，不再给出看似可用的阈值；数值法拒收缺失或非数值的概率；正向决策器推理失败的牛下一轮自动重试（以前要等到新文件到达）。

## 2 桌面端：业务流程入口与失败恢复

- 主窗口新增 **业务流程**（F1 同样打开）：核对台账 → 下载与归类 → 打开工程并标注 → 核对推理设置 → 查看风险报告，每一步都有按钮直达原有功能；窗口不阻塞，可以边看边做。
- 下载菜单新增 **重试失败批次**：继续同一台账中失败的批次，已下载的数据由原下载流程核对后跳过。
- **风险等级总览**：已生成时直接打开；尚未生成时打开下载窗口，并提示核对推理路线、查看运行记录，不再没有反应。
- 算法引擎本机接口：非 JSON 对象的请求、非法 `Content-Length` 返回明确的错误，连接不再中断。
- 新增界面文字均有英文。

## 3 全流程 4.4.7 对齐

- 目录树中 `常规经典算法` 与 `AI大模型算法` 的 `3_训练器 / 4_逆向决策器 / 5_正向决策器\产犊\4.4.7` 六个包共用代码逐字节一致，并与本软件 4.4.7 相同；数据集、行为识别模型、监测记录随版本迁入，其余在 4.4.7 重新训练、回溯与推理。

## 4 本次训练与回溯（扬大_高邮牧场，本机，2026-10-03）

数据集 11072 个决策小时 · 157 头牛 · 156 次产犊（金标准 29 次，比 4.4.6 多 7 次；台账 127 次）。两条路线都用按牛分组的留出概率，走 4_逆向决策器 同一套预警规则与风险等级打分：

| 路线 | 标签 | 产前 12 小时内中风险及以上 | 产前 3 小时内高风险 | 中位提前量 | 误报（次/头·天） |
|---|---|---|---|---|---|
| 常规经典算法 4.4.7 | 金标准 | 17/25 | 14/25 | 11.0 小时 | 0.42 |
| 常规经典算法 4.4.7 | 台账 | 104/114 | 89/114 | 9.2 小时 | 0.38 |
| 常规经典算法 4.4.6 | 金标准 / 台账 | 16/25 · 96/107 | 15/25 · 88/107 | 6.7 · 9.5 小时 | 0.47 · 0.42 |
| AI大模型算法 4.4.7（light · 数值法） | 金标准 | 19/25 | 12/25 | 7.6 小时 | 1.32 |

- AI大模型算法 只在金标准牛上留出评估（906 个产前 48 小时内的小时，参考病例排除本牛）；逐小时 AUC：1 小时 0.75、3 小时 0.68、12 小时 0.59。检出与常规相当，但误报约为常规的 3 倍，**常规经典算法仍是主力**，AI 作为并行的第二意见；各模型 × 推理方式的对比见 AI 3_训练器 `训练结果\模型对比`。
- 纯样本外（5_正向决策器 的实时记录，台账补上结局后打分）：常规路线已有结局的 79 头中 3 头产犊，产前 12 小时内均未预警——实时环节的漏报是下一步的重点。
- 金标准样本小（25 次可评估）、单牧场，区间较宽，不能当作独立外部验证。

## 验证

- 全部测试：2346 项通过，已知 3 项未变（翻译积压 2 项、录像替换后重试 1 项，4.4.5 起即如此）；新增 `tests/test_workflow_navigation.py`（业务流程五步直达、风险总览缺失时的提示、重试失败批次）与 `tests/test_engine_http_contract.py`（非法请求不影响后续请求）。
- 产犊算法回归 56 项通过：推理身份与固定路由、响应与概率契约、阈值与评估一致、候选推广与中断恢复、实时推理失败重试。
- 六个算法包环境检查：所有位置都由目录树相对位置解析到同一棵目录树；三个本机模型均通过身份核对。

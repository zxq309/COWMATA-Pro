# COWMATA Annotator 3.6.4 纯净版

## 启动

双击已解压便携文件夹中的 COWMATA.exe，直接进入软件。更新在主窗口打开后后台检查；HTTP 403 限流、断网或代理错误不再弹出启动门槛。自动检查增加半小时节流，手动检查入口仍在“帮助 → 关于 → 版本与更新”。不会为解决网络问题关闭证书校验。

## 数据归类

选择牧场、视频总目录，再勾选视角。每个视角独立处理，第一份文件的临时复制立即开始，与该视角的健康核验重叠；一个视角较慢不会占走其他视角的处理槽位。临时文件存放于任务专属的 `.归类缓存` 中，只有健康核验、日期识别和复制校验通过后才进入 Video/日期/视角。

同盘移动是核验和日期识别后的原子重命名，通常瞬间完成；各视角独立进行，不等待其他视角结束。跨盘仍复制保留原件。所有视角同时启动任务，并不意味着每份文件的核验与最终归档会在同一时刻结束。

已归类、来源和目标均未变化的文件仍直接复用。暂停保留断点，确认全程黑屏、空录像或损坏才删除；短暂黑帧、暗画面、超时、占用或权限问题不能作为删除依据。

“耗时”是本文件从开始处理到归档完成的实际经过时间，包含核验及排队，不能把并行阶段耗时相加。总任务耗时按本轮实际运行时间计算。运行中的文件耗时每秒更新。“打开完整记录”另列核验、识别、传输耗时及开始/结束时间；传输时间包括字节复制与复制校验。复用记录显示本轮耗时 0。

选择新总目录会清空当前列表、旧详情、进度和实时记录关联，历史 CSV 保留在原任务目录。主窗口下方的详情框已移除；“打开实时 CSV”后新增“打开完整记录”，独立窗口固定查看所打开任务，不与新的总目录混用。Excel 直接打开 CSV 仍是快照，实时查看请使用工具内窗口。

## 端侧数据下载

参照桌面下载器 MotionDownloadManager、ServerRecordConverter、MainWindow 和公开证书资源同步下载行为：

- 新牧场默认设备服务器 `http://device.cowmata.com:8010`；已有牧场服务器设置保留。
- 设备服务器按设备查询清单、按 UID 请求详情；3090 适配接口仍保留设备参数及牛号跨设备查询。
- 牛耳标可留空。服务器有历史牛号则使用并核对；没有时保存到设备的“待核对”目录，不猜测归属。
- Motion、PPG 及温度原始数据可选；温度 JSON 保存到牧场/类别/Temp/日期/设备-牛号-记号，不混入 Motion 或 PPG。
- 网络请求采用 30 秒无新数据超时，取消原先 5 分钟总下载限制。初次失败后最多重试 3 次，延时为 250/500/750 毫秒；记录校验失败也在当前轮重试。停止后不再执行延迟重试。
- 外部 JSON/BIN、响应长度、原始帧与哈希校验、同内容去重、同秒冲突保留和原子写入沿用标注工具实现。
- 为 data.cowmata.com 加载桌面下载器相同的三份公开 CA 证书，校验指纹和有效期，保持证书及主机名验证；该数据域的重定向限定同源，拒绝 HTTPS 降级。
- 手动、自动、定时、迟上传补下、多牧场和 SSH 功能继续保留。

下载器协议通过本地模拟 HTTP 服务及固定测试数据验证；未连接用户的真实远端服务执行下载。该版本同步下载相关逻辑，不把旧独立下载器的绘图/仿真模块嵌入标注窗口。

## 交付

仅生成源码 ZIP 与已解压便携文件夹。本版不更新 GitHub，不生成安装程序。便携包不含个人设置、私钥、日志、下载历史、归类任务或采集数据；公开 CA 证书属于程序组件。

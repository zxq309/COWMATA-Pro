# COWMATA 3.4.3 - 3.4.2 六项问题修复

1. **录像时长**：播放器显示完整文件的实际时长，不再用已核验区间长度代替。没有当前录像时清空旧进度，显示不受滑块取整或相机校准比例影响。
2. **同名摄像头**：同一路不再因分辨率、OSD 角落或 unknown 拆分。旧的自动生成名称归并到原视角；明确自定义的相机名称保留。旧校准记录继续沿用，有冲突时保持待核，不自动选择。
3. **人工核验后无画面**：保存后立即刷新定位。一个人工读数也可建立连续片段的浏览关系，两个读数之间才能标为已核验；首尾外推保持待核。重建索引时恢复人工读数，并防止后台旧结果覆盖新保存。
4. **对齐后旧标签移动**：按用户确认的规则，已有九轴标签和已投影的视频草稿固定九轴起止。同步修订只更新录像对应关系并要求复核，保留历史版本及撤销。
5. **标签排序**：视频草稿与九轴标注按时间混排；排序不改变记录编号，也不丢失当前选择，新标注仍自动选中。
6. **状态互斥**：站立、躺卧、行走在新建、确认、编辑和拖动时拦截重叠。首尾相接允许，甩尾等不同层事件仍可与状态共存。已有历史标签不被自动删除。

新增“数据整理 → 导出标准 MP4 副本”，用于流内时间连续、可核验的摄像机 PS 录像。输出保持视频编码不变，逐份核对完整帧数与时长；仅导出视频画面，原文件及其音频、私有数据包完整保留。它不会覆盖原片，也不会凭假定的一小时填补缺失录像。

本地实测的 `2026-08-03_11-51-05.mp4` 内部为 Hikvision PS，有效连续视频为 973.631 秒、12181 帧。首帧 11:51:05、末段约12:07:18。末段白色数字与背景混合，自动 OCR 未完全通过，放大目视与流内时间复核一致。标准 MP4 副本时长恢复为 973.631 秒；原始 SHA-256 未变。没有将此结论推广为全部视频的实际时长。

# 3.3.2 验证范围

以已发布的 3.3.1 为基础，修改检索调度、困难画面识别限时、素材状态说明和区间显示；不修改原始 JSON / 视频或标签导出格式。

- 复现：同一时间范围携带新播放位置或保存进度重复提交时，3.3.1 会把结果取消为 pending；修复后可完成并进入待复核。真正更换时间范围、相机校准或暂停仍能取消旧任务。
- 复现：受控的无时间戳短片场景可触发 144 次识别调用；新增单画面限时及连续失败预算，退出后不取消下一份素材。实际模型调用在调用间检查，正在执行的一次推理可能超过限时后才返回。
- 界面：待确认悬停显示适用于当前状态的操作；闭合草稿和标签显示完整淡色区间，点事件不伪造持续时间，缩放不越出绘图区。播放复用着色缓存。
- 数据：草稿映射只用于显示，不自动确认为真值；不同牛号和记录外草稿不投影。删除、两端调整、撤销、保存和重开保留身份与原有证据规则。
- Windows：使用本机授权录像与隔离演示工程进行实际界面、录像时间识别和操作验证；最终安装器及 3.3.1 更新器另行验证，详细结果和边界写入 Delivery-Checks.json。

客户截图中的 imou00162.mp4 只在客户电脑上，无法声称已对那份原文件实测。已在可重复的异常场景中验证调度与限时修复，本机原片用于播放和识别回归。时间匹配不等同于牛身份自动识别，仍需人工核对画面中的牛。

本机实测：源码完整回归 774 项通过、5 项二进制组件条件跳过；实际 FFmpeg 与发布 OCR 引擎在无时间戳短片上用时约 14.6 秒后转待复核，随后实际牛舍短片约 8.5 秒取得三处读数并建立已验证区间。该耗时只代表本机两个短片，不能外推客户长录像。

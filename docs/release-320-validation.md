## 播放与交互

4 份不同原始监控重复配置为 8 个视角槽位，1,000 份九轴列表，只解析选中的 1 份。九轴是用于计时的合成 50 Hz 连续信号。Windows 解锁、压缩任务结束后测试。

| 项目 | 本次结果 |
| --- | --- |
| 选中九轴解析就绪 | 0.712 秒；另 999 份未解析 |
| 首个可用原片帧 | 2.873 秒 |
| 4 份匹配候选元数据 | 6.219 秒；并非全部视觉核验完毕 |
| 66 秒单主路播放期间 GUI 队列延迟 | P95 3.19 ms，P99 5.13 ms，最大 107.68 ms |
| 4 次视角切换期间 GUI 队列延迟 | P95 3.45 ms，P99 17.90 ms |
| 播放、切视角、跳转、放大、倍速、暂停按钮回调 | 0.13–18.14 ms |
| 切换后解码画面就绪 | 1.53–4.91 秒，不能等同按钮响应时间 |
| 暂停后 8 路原片帧 | 均就绪且同参考时刻误差不超过 1 秒 |
| 播放期后台缩略图 | 不循环刷新；最多 1 个提图任务 |

冷加载 GUI P95 为 57.23 ms，打开与配置回调分别为 162 / 379 ms；不宣称任何操作永远小于 25 ms。测试日志含原录像音频头警告及切换时 VLC 硬解缓冲警告，最终画面就绪检查通过。结果不是八路同时全帧率播放的保证，也不是所有硬件的稳定性承诺；保留软件解码兼容选项。

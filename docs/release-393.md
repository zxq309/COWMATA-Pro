# Cowmata Pro 3.9.3

本版统一下载、温度提取、数据集生成与温度相关模型的输入约定。

- Motion、PPG、Temp 均使用北京时间的 YYYY-MM-DD_HH-MM-SS.json。v2 Motion 使用 create_time 加首帧设备计数；PPG、Temp 使用自身 create_time。保留原始毫秒时间。
- 手动、CSV、自动下载统一命名。真实同秒内容冲突明确报错；损坏文件先保留原始字节，再恢复规范名称。温度差异参与 Motion 去重。
- 独立温度 data 是一个有限摄氏度数值。旧 Motion 的有符号小端 int16 温度按原值除以 100，导出到 Temp/日期/设备-耳标-现场记号。原始 Motion 与 Raw/Label 配对保留。
- 从 Motion 提取的温度采用首帧时刻与温度桶中点估计；额外 _temperature 记录来源 SHA-256、原始整数、序号和估计依据。UID 使用可追溯字符串，缺失电量保持 null，不伪造服务器 UID 或真实独立采样时刻。
- Raw/Label 数据集和母标签数据集均附带相同独立 Temp 格式；综合决策兼容独立 Temp 与历史内嵌温度，并防止同源样本重复计入。
- 温度相关综合决策训练、导出、导入与推理使用 cowmata-temperature-1 摄氏度契约。无契约的已有 Celsius 版本继续兼容，显式错误单位拒绝导入。行为识别九轴特征保持原有定义。
- 预测时仅使用决策截止时刻前已接收的温度，防止迟到数据进入较早预测。

发布包不包含牧场资料、现场 CSV、账号、用户配置、训练数据集、已训练行为或温度模型、开发缓存。包含运行所需的基础 OCR 资源和依赖。3.9.2 原目录保留。

详见 [温度数据约定](temperature-contract-393.md)。

已移动的轻量标注工程在母标签导出时优先解析当前所选目录中的相对原始路径，旧盘符提示仍保留为来源记录，避免因历史 G 盘路径失效而遗漏标签。

3.9.2全版本升级实测发现的旧版问题已纳入本版：对3.1.0-rc.1至3.4.3的已核验官方清单按SHA-256识别旧版本，不修改旧清单；升级器使用新版进程探测器，兼容缺少进程检查参数的最早RC启动器。安装事务继续保留哈希检查、未知文件保护、降级拦截和失败回滚。旧客户端自身的旧协议、缺失安装标识或网络限制不能通过发布新版本追溯改写，可使用本版安装器或随包“修复旧版更新”入口。详见[升级兼容说明](upgrade-stability-393.md)。

本次用户反馈修复：

- 首次打开九轴显示完整记录，提供“完整记录”与可切换的“平移”按钮；Shift 平移优先于标注边界拖动。
- 鼠标停留时继续显示该点的时间与精确数值，不再被通用操作提示覆盖。
- 历史标签保留原始编码与事件，并分配可用快捷键；不显示空的 []。
- 自动候选在没有模型时说明原因，并提供导入或训练入口；模型列表在返回窗口时刷新。
- 行为训练、训练历史、评估和识别表格列宽随窗口变化填满可用区域。
- 缺少视频时取消目录选择仍可继续打开九轴记录。
- 默认数据集与模型目录优先采用现有的 F:\科牧特_数据集、F:\科牧特_模型。
- 数据归类支持独立 Temp，PPG 和 Temp 采用秒级时间戳名；同秒不同内容明确停止覆盖。
- 产犊训练兼容台账分开的日期与时刻、完整日期时间及带时区时间，不用仅日期记录伪造精确生产时间。

产犊预测增加手动开启的“文件夹滚动预警”：选择连续多日 JSON 后直接生成逐时段结果，显示覆盖与缺口、参考历史是否达到 24 小时、连续预警段和未来关注窗口。建议连续 3–7 天，默认准备 3 天；该建议仍需本牧场验证。预测不要求另交台账，使用事先导入的决策模型及其确切行为模型依赖。详见 [文件夹预测说明](calving-prediction-393.md)。

新增录像与信号功能：

- 数据归类新增独立原始录像页签，支持经过实测的 DHFS4.1 磁盘只读解析、DAV/DHAV 解码、时间范围截取、跨日拆分、人工视角映射、MP4 归档及暂停恢复。详见 [录像准备与命名规则](dahua-import-393.md)。
- 20 路视频按每组最多 8 路翻看，主界面加载已归类 MP4；标准时间戳视频按文件名直接加载，保留媒体时长与内容身份检查，不重复 OCR。
- 原始录像视角表格采用随字体和缩放调整的紧凑行高，点击缩略图查看大图。
- 九轴、PPG、温度分为三个曲线页签，切换保留时间范围、播放位置和同一份标签；按牛号、设备、现场记号及采集时刻关联，缺测保留为空。
- 数据集附带共享行为标签索引；训练从当前来源标签重新关联，模型携带共享标签协议，冲突不静默合并。详见 [三类信号和标签](SHARED_SIGNALS_393.md)。

2026-09-17 修复补充：

- 常规归类改为后台发现视角与统计文件，视角逐步显示，可取消或切换来源；扫描完成后再执行归类。
- 原始录像默认显示自动识别的盘符、物理磁盘、型号及容量，选择支持的录像机原盘后自动只读扫描。普通 DAV 目录改用非系统目录选择器，发现来源时不全量哈希视频；预览及转码时继续校验完整来源。
- 首次进入主界面后后台检查更新；发现新版本自动提醒，每次启动最多提醒同一更新一次。
- 用户启动更新后，升级器向同一安装目录的其他实例请求正常保存退出；取消保存时继续保护旧版，不强制结束或覆盖运行中的程序。

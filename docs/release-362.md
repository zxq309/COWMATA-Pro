# 3.6.2：真实归类状态与实时 CSV

- CSV 精简为 8 列：序号、状态、采集日期、视角/设备、来源文件、归类位置、耗时、说明。
- 每个来源文件只保留一行最新状态。界面、实时记录窗口和 CSV 来自同一快照；状态变化不会重复追加数据行。
- 全部待处理来源进入清单，明确区分已归类、复用、待处理、处理中、无录像内容和真正异常。
- “打开实时 CSV”提供每秒自动刷新的记录窗口，无需关闭重开；可另存当前快照。Excel 直接打开 CSV 本身不会自动刷新。
- 摄像机全零预分配文件会经过完整核验后标记“无录像内容”，保留原件、缓存结论，不再反复调用解码器或要求手动调日期。
- 只读首段不足以判定全零：中段或末尾有数据的文件仍进入正常媒体识别流程。
- 已完成且文件身份未变化的归档继续复用；真正完成的复用记录不会重新复制。暂停时保存最新状态。
- 端侧下载、标注及已有数据格式保持兼容。

CSV 第一列的序号与界面文件总数对应；Excel 自身的行号包含一行表头。
CSV 的精简不丢弃追溯信息，任务 JSON 与事件日志继续保留来源、校验和完整过程。
全零文件不含可恢复的视频帧，不能按正常录像伪造日期归档；其数量单独列出，不计入归类成功数。
发行包不包含个人配置、密钥、下载历史、测试数据或运行缓存。

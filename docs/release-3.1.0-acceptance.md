# 3.1.0 发布前验收

2026-09-07 · 构建 evidence-r5-20260907 · Windows x64

## 功能与数据

- 全量回归：465 项通过；Ruff 通过。包括新旧时间协议、历史片段、同步门槛、索引安全、截图/归档、安装与更新事务。
- 11 份真实 JSON、1,437,437 个样本：首/中/尾采集时间、片段往返及原件字节完整性通过。文件名类别涵盖旧/新整小时和半小时上传；实际帧协议均为 V2，V0/V1 兼容另由合成协议测试覆盖。
- 截图：同一参考时刻，每个选中视角一张，独立原片 PTS、图像 SHA-256、标签/牛号/同步上下文；缺片、过大帧偏差、未核验时间、取消、损坏图、路径越界和导出失败保护均有测试。
- 离线成果：单个标签 JSON 加一个同级证据文件夹；迁移后可读取原九轴/片段、静态图与原始分辨率放大；不把图片送入九轴模型。
- 归档：比较完整原片/副本 SHA-256；改名副本按核验记录重新定位，不在归档创建索引，不自动删除原片。缺失或不同内容不能报告全部通过。

## 真实程序与私有运行库

三个真实监控场景（1280 × 720 演示副本）完成原片提图、人工确认保存、离线回看/放大和改名归档重连：三张图约 1.46 MiB，提取约 1.78 秒。受控八路 2560 × 1440 HEVC 录像试验完成同样流程：八张图约 15.57 MiB，提取约 5.81 秒。

上述“原片”指各自验收工程的录像文件，截图不再缩放；高清八路为受控重复真实画面负载，不冒充八个独立真实相机。时钟与标签均为 DEMO 操作示例，不构成科研同步或行为准确性证明。实测帧相对请求偏差为三路不超过 40 ms、八路不超过 36 ms；这是解码定位误差，不是设备与相机总同步误差。性能数字仅对应本机和这组输入，不保证所有硬盘/GPU/编码条件。

实际安装包包含全部私有运行库。限制 PATH、阻断 Python 网络后的自测通过：原始 2560 × 1440 录像解码与 RapidOCR PP-OCRv6 medium/OCR 轻量 v2、真实 V2 数据、全部五类事件模型、原始 JSON 与片段独立回看。模型运行输出仍是候选，不是自动真值。

## 八路连续播放

独立固定时钟工程，八路受控重复真实 2560 × 1440 HEVC 画面；本机 RTX 2080 Ti、24 逻辑处理器，VLC 日志确认 D3D11VA 硬解。全速与均衡模式各播放 120 秒，均完成两次回绕、每视角跨两个录像文件、主视角/A/B/C 布局切换；暂停后八路均恢复原片 PTS 精确帧，原始测试文件摘要不变。

| 本机指标 | 八路全速 | 均衡模式 |
| --- | --- | --- |
| 主画面显示帧率中位数 | 12.01 fps | 12.04 fps |
| UI 心跳间隔 P95 / 最大 | 22.93 / 329.47 ms | 22.91 / 293.62 ms |
| 应用峰值驻留内存 | 2585 MiB | 1636 MiB |
| 主画面就绪比例 | 95.8% | 93.7% |

这批输入约 12.51 fps；均衡模式的辅视角是低频预览，不声称八路均按原帧率播放，原帧提取最多并行两路。均衡模式降低本次内存/同时播放负载，但不承诺所有资源都降低：本次 UI 进程 CPU 时间反而由约 45 秒增至 70 秒。轻量笔记本仍须按其编码、GPU、磁盘条件选择模式。

保留的两次旧工程试跑未启动实际八路播放，因此明确判为失败，不计性能验收。原因是旧测试固定时钟被新 OCR 迁移重新识别；重建带明确测试锚点的隔离工程后重跑，未降低播放验收阈值或修改生产索引迁移策略。

## 安装、更新和卸载

实际安装本地 rc2，使用它自身的更新控制器/独立运行库更新到 3.1.0。测试将本地已校验安装包提供给旧控制器，随后走真实“保存退出 → 校验解包 → 原位置替换 → 重开”链路。未保存的测试标注先落盘；外部九轴/标注未变。约 96.2 秒，不含网络下载。

新版真实 EXE 的窗口图标与牛图标匹配、与 Python 图标不同；运行中卸载被拒绝。正常卸载约 60.3 秒，安装目录清空，客户数据目录仍保留。整个新截图/归档流程另在安装后的私有 Python 中重跑通过。

GitHub 首轮发现构建脚本使用了宿主路径语义：Linux 没有拒绝 Windows 盘符路径。已改成显式 Windows 路径解析，并补测盘符相对路径、根相对路径、反斜杠越界和 NTFS 数据流；不放宽测试。修订不属于客户端运行载荷。核对既有真实安装包与修订生成结果：全部安全检查、文件删除指令及其顺序相同；目录清理对象及子目录优先顺序相同，仅同深度、同长度的互不依赖目录有集合遍历排序差异。

后台更新要求完整 Release 清单、GitHub 资产摘要及安装包/载荷校验。旧无更新器版本仍需手动引导一次。上述本地验证不等于已完成公开网络下载；发布后的网络检查/下载/更新结果应另核对，不能以模拟传输替代。

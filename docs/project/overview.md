# COWMATA Pro™ 项目简介

COWMATA 是杨凌园上园智能科技有限公司的牛尾环与配套软件项目。现场以连续九轴、温度、PPG 和同步视频记录奶牛行为；COWMATA Pro™ 负责把数据整理成可追溯的标注和数据集。

操作员的主线是：获取原始数据，按日期与视角归类，对齐视频与信号，标注、复核已有记录，再导出成对的 Raw/Label 数据集。自动识别只负责缩小人工检查范围。

尾环牧场版和兽医版体现不同使用场景；产犊是当前优先实验方向。发情、怀孕与健康/疫病需要各自的真值、模型和独立验证。温度与活动量输出辅助证据，尚不能据此宣称完整的融合产犊概率或诊断能力。

本仓库集中维护桌面软件、当前算法接入、数据集规范、操作教程及研究来源。原三个仓库的总体介绍、接口、训练方法与实验说明已整合至[历史资料入口](repository-consolidation.md)，对应全部提交可在本仓内访问。

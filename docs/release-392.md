# COWMATA Pro 3.9.2

本版整合本地 3.9.1 修复，并恢复 GitHub 正式更新链路。

主窗口标题简化为 COWMATA Pro。

## 数据准备

- CSV 下载对象表格独占整行宽度，列标题与内容保持可读；记录多时纵向滚动，窄窗口横向滚动。主窗口保留下载方式、数据类型、列表和开始/停止；路径、时间、账号放入“配置下载”，日志、连接检查和目录入口放入“更多”。
- 配置自动带入，一键保存并读取 CSV；关闭配置窗口会撤销未保存的改动。旧默认 CSV 目录不存在时，识别本地已有的完整三个 CSV，自定义路径保留。

- 定时启动和补齐终点的默认值统一使用北京时间，不随电脑本地时区漂移。
- 现场数据下载进入后先选择手动、自动或定时模式，由用户启动；打开窗口、保存设置不会开始任务。
- Motion / PPG 使用原始 JSON 内容及时间戳文件名，例如 `2026-08-18_00-41-42.json`。
- 下载前跨分类核对本地原始记录，按类型、设备和 UID 去重；已有有效数据保留，只补缺失记录。
- CSV 的监测目的与台账上传器 1.3.1 对齐；没有依据的分类仍保留为未分类，异常配置给出问题行。

## 更新兼容

- GitHub API 限流时使用官方发布订阅与附件页；TLS 中断进行有限重试，并可使用 Windows 系统网络通道。
- 支持当前便携 ZIP 和安装器原位升级、完整校验、失败回滚及完成后重启。
- 最新 Setup 可直接升级 3.8.0 及以上旧安装版或便携版目录。便携版通过 Setup 升级后转为安装版，原位置保持。
- Release 保留旧版识别的更新清单，3.8 系列安装版在原更新器正常联网时可直接升级。
- **旧更新器本身遇到 403、旧地址限制、目录拒绝或便携版不支持更新时，须运行一次本版 Setup，并选择旧软件所在目录。** 旧程序无法仅凭 Release 内容自行修复本地代码。完成这次兼容升级后使用新版自动更新通道；无需逐版安装。
- 若程序目录混有用户文件，会停止并指出文件，不会删除它们。把数据工程存于程序目录之外后再升级。

Windows Computer Use 的实际发布后升级结果另见验收记录，不以模拟测试替代实际下载安装。

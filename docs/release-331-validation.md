# 3.3.1 发布验证

本次修复经过 Windows 实际播放、Qt 标注操作及完整源码回归。证据范围与修复前后对照见 [播放与标注修复](playback-annotation-fix-20260910.md)。

- 767 项源码回归通过；源码目录缺少的 5 项模型组件检查在完整软件中另行核验。应用和测试目录的 Ruff 检查通过。
- 真实监控 MPEG-PS 样本：1/2/4 倍速实际时钟与显示帧推进正常；缓存大段前后跳转约 0.12 秒；同片连续跳转共享准备任务。
- 真实异常音轨封装复现：修复后 75 帧视频解码 MD5 与原片一致；实际播放、候选式暂停回看及续播通过，原片 SHA256 未变。
- 动作状态、数字键、取消、草稿投影、独立拖边、时间输入、撤销重做、保存重开、跨记录与证据保护均有回归。
- 软件手册使用实际 Qt 窗口截图；演示数据与标签不作为研究真值。安装向导布局沿用 3.3 系列实拍。详见 [手册验证](manual-331-validation.md)。

发行时另核验完整便携包、安装与卸载、3.3.0 更新器迁移、启动器版本和文件 SHA256。生成安装器后再记录最终哈希，避免把安装器自身哈希嵌入其内容造成循环。最终结果随发布附件 **COWMATA-3.3.1-Delivery-Checks.json** 提供。

本次没有重新训练模型或评价识别准确率。用户提供的八月录像与合成异常音轨覆盖本次缺陷；九月客户原工程尚未在本机直接验证。磁盘、视频 GOP 和显卡差异可能影响加载时间。

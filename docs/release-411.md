# COWMATA Pro 4.1.1

本版本继续修复 4.1.0 的视频恢复路径。版本标记变化时只清理软件自己登记的兼容缓存，不删除原始录像、标注、证据或恢复中的任务缓存。

原始录像归类现在对 MPEG-PS、扩展名不可信和首帧探测失败的文件使用分层探测；无法证明时间的文件会保留并进入待核对列表。大华归类任务默认具有 8 小时硬截止，20 路任务保持公平调度，同时限制物理源盘读取并发，避免中段吞吐骤降。

派包方案按设备日、记录数量和字节量均衡，仍保持同一设备日完整进入同一个包。完成的归类任务会自动撤销阻塞性恢复标记；标注历史和归类报告继续保留。

九轴曲线按窗口高度自适应，DOCX 上传先校验 ZIP 结构、大小和路径，再进入后台处理。

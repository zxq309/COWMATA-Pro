## 修复：标签等画面到位后仍无法确认
- 非大华品牌录像机的原始码流（MPEG-PS，扩展名 .mp4）索引时只用“相邻文件名”估算时长，时间永远是“待复核”。现在依次读取大华帧时钟 → 录像机原生时钟 → 数据包时间轴，读到即自动核验；录像机时钟与文件名相差超过 2 秒、或数据包时钟不连续的才保留“待复核”。实测高邮牧场 2026-09-06 10 点前后 6 段录像：由 5 段待复核降为 1 段（真实的时钟跳变）。
- 已建立的工程打开时自动重新索引旧的估算结果一次；人工标注不受影响。
- 确认真值：视频不在这条动作上时先自动跳到动作开头；确认失败写明原因（画面加载中 / 哪个录像时间未核验 / 校准被改 / 文件变化 / 此刻没有录像），时间未核验时可一键“去核验该录像”。
- 旧标注（旧工程、协作回传、模型生成）回到动作后可直接确认真值，保留原编号与备注，一次撤销即可还原。
- 标注列表与历史回看的状态显示中文（已确认 / 需复核 / 旧标注·待确认）。

## 修复：找不到需要核验的录像
- 素材核验窗口：默认“当前记录用到的录像”，需核验的标黄置顶；可切换“需要核验时间的录像 / 全部录像 / 全部素材”；汇总需核验与未索引数量；“定位当前画面录像”；双击黄色行直接核验。
- 录像时间核验窗口：“读取开头画面 / 读取结尾画面”，预填读数（需与画面逐字核对；手动输入不会被覆盖），实时显示已核验范围与比例。

# COWMATA Annotator 3.3.1

本次修复视频播放与动作标注，保留“数据整理 → 标注保存 → 复核导出”工作流程。

1. 修复异常音轨造成的“兼容封装失败”和播放黑屏；原录像保留。
2. 暂停画面显示后后台准备播放，连续拖动共用一次准备，完成后定位最新目标。
3. 修复数字标注键被拦截、未结束动作提示隐藏；明确显示正在记录的动作，并支持确认取消。
4. 视频草稿可在九轴上分别拖动起止边界，或输入时间戳、按 ±0.1 秒微调；修改后仍需回看和确认。
5. 同步修复起立、卧倒、排尿、抬尾、甩尾候选的公共播放回看通路。
6. 更新图文手册。安装版启动后直接检查并升级到最新版本，无须逐版安装。

## 下载

- **Setup.exe**：完整 Windows 安装版，包含播放器、OCR 和行为模型运行组件。
- **Portable.zip**：完整解压后运行 COWMATA.exe，无须安装运行环境。
- **Source.zip**：纯净源码，供开发维护；普通标注用户选择前两项。
- **Manual.pdf**：图文操作手册；SHA256 文件用于校验对应下载。

八月录像样本在本机使用缓存后，大段前跳、后跳约 0.12 秒；首次准备和实际速度仍取决于素材与硬盘。详情见 [验证记录](https://github.com/zxq309/COWMATA-Pro/blob/v3.3.1/docs/release-331-validation.md)。保留旧版发布附件供追溯，自动更新只选择最新版。

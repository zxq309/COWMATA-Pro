# COWMATA Annotator 4.4.8

本版面向现场回传、派包录像和多视角标注稳定性，修复以下问题：

- 旧版 ZIP 协作包：接收 Windows 压缩文件夹产生的目录项、单层外包装目录，以及未标记 UTF-8 的 GBK 文件名；仍拒绝越界路径、链接、加密和重复成员，并按 SHA-256 解包。
- 标注回传：清单外文件不再阻断接收，全部忽略且不导入；报告列出数量、路径，并提示是否与清单内疑似副本一致。
- 行为识别模型：软件可随包携带模型；现场没有目录树训练器时仍可“自动生成候选”。目录树中较新的训练器模型仍自动优先。
- 派发录像：每个视角补入跨零点可能覆盖的相邻日期录像；派包预检增加每视角文件数、首末时间，以及无覆盖或目录异常提示。
- 新包增量索引：每新增一路可用录像，只启动该路暂停帧，不再取消并重算已经到位的其他视角；精确帧仍核对原片 PTS，预解码窗口由 15 秒缩短为 3 秒。
- 标注复核重连：人工重新选择数据工程后，九轴原件与原录像同时改用新位置；兼容派发包外层目录、农场相对路径和旧分类相对路径，不再拼出重复的 `产犊\产犊`。
- 菜单稳定性：显式保留菜单对象所有权，避免工程、下载、数据归类和账号菜单在 Qt 包装对象失效后无法访问。
- 下载菜单新增“正向决策…”窗口：可运行一次决策、盲测、盲测评估，打开报告与结果目录，并显示评估摘要和逐头明细。

视角命名、分组和选择逻辑保持 4.4.7 原样，本版不调整。

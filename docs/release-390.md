# COWMATA Pro 3.9.0

## 交付内容

- Windows x64 安装包：`COWMATA-Pro-3.9.0-Setup.exe`。
- 便携 ZIP 与解压目录：直接运行 `COWMATA.exe`，包含运行库。
- 源码 ZIP：开发环境、安装、训练与决策配置见统一 [README](../README.md)。
- 行为、决策和历史温度训练模型保存在外部模型库，不随程序包分发。

## 本版改进

### CSV 自动配置下载

读取 `F:\牛舍\_现场记录` 的三个 CSV，自动生成设备、牛耳标、现场标号和佩戴时间下载任务。完整 12 位设备编码保持原编号；仅 4 位简写补 `546C50CA`。无现场标号时不添加末尾空段。

文件夹示例：`546C50CA07E5-21314-D2`、`546C50CA090E-23060-I`、`546C50CA090E-23060`。

支持 Motion、PPG、Temp；保留原始 JSON，核验后跳过已完成数据，重新查询可补晚到数据。CSV 修订后重新解析身份，保留旧文件并报告冲突。下游标注、数据集、行为识别和决策使用共同输入约定。

台账连接与上传器 1.1.0 保持一致。本地目录是 `F:\牛舍\_现场记录`；服务端受限协议目录沿用 `F:\牛舍_现场记录`。使用本机已有授权；包内不含私钥、真实台账。同步状态和备份放在 `%LOCALAPPDATA%\COWMATA-Pro\site-records`，业务目录只保留三个 CSV。

### 行为识别与综合决策

新增“行为识别”菜单，位于数据集构建和健康与繁殖之间。下拉独立选择起立、卧倒、努责、排尿、抬尾、甩尾，以及 Motion / PPG；提供训练和识别页签、全部输入记录、训练历史、评价与可视化。

每次训练一个行为、一种模态，识别前手动导入模型。“自动生成候选”与行为识别共享对应行为、模态的同一导入模型，已修复 PPG 候选传递模态不完整的问题。

产犊界面提供“数据与证据 → 决策训练 → 综合决策”。综合行为、活动量、躺卧可知占比、温度及覆盖率。心率和血氧保留缺失字段，不将未经验证的光学信号转换结果作为实测指标。

决策支持 XGBoost 3.4.1、随机森林、决策树，6 / 12 / 24 / 48 小时提前量。按牛分组验证，隔离训练折填补参数，保留原始指标、缺失值、评价和版本信息。模型库固定为 `F:\科牧特\_模型`。

### 更新下载与安装

修复 GitHub 匿名 API 403 导致更新中断的问题：自动转向同仓库官方发布页和资产，普通用户无需填写 Token。下载支持暂停续传、有限网络重试、签名地址刷新和 SHA-256 校验。

安装版优先下载 Setup；便携版优先 ZIP。独立更新程序等待正常关闭，校验新文件及运行库后替换，失败时回滚。有效的盘根软件文件夹可更新，磁盘根目录仍禁止覆盖。

旧客户端自身无法更新时，直接运行新 Setup；便携用户可使用新版中的“修复旧版更新.cmd”和完整 Portable ZIP。

整合三个旧仓库的 README、实现说明与方法边界，统一整理为当前 README。新手教程重新截图，说明配置、安装、下载、一次对齐、标注、训练、识别与综合决策。补齐新增界面英文文案，CSV 字段、文件名和路径保留业务原值。

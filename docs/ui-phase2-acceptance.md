# 3.1.0a2 界面阶段验收（2026-09-06）

本阶段交付可运行的原生 Qt 界面预览，不是效果图。默认采用用户选定的 A 观察优先；旧版控制器、索引、时钟、真值校验和保存逻辑继续复用。界面改造按小步实施、独立验证；未重写原始录像或九轴数据。

## 本阶段功能

| 需求 | 实现与入口 |
| --- | --- |
| 默认大录像 | A：大主视频、滚动辅视角、底部九轴；1–8 路由素材面板选择 |
| 同时多画面 | B：所选视角网格；各路仍使用同一参考时间 |
| 波形优先 | C：大波形、可拖动画中画；画中画小/中/大三档，避开工具栏和标签轨道 |
| 切换不中断 | 仅调整原播放器几何位置，不重建播放器、重新打开文件或发起 seek |
| 单路放大 | 原有双击画面/放大按钮保留，Esc 返回，Alt+1…8 切主视角 |
| 节省空间 | 素材、标注列表可展开；详细编辑/确认/补证据/删除收进列表侧栏；旧菜单完整收进“更多” |
| 波形清爽 | 九轴按三组 XYZ 显示，可单选加速度、角速度、磁场或温度/活动量；原始数值及单位悬停查看 |
| 标签独立 | 单独标签轨道，可滚动；点击选择，波形拖动选中边界，原表格仍可编辑；待复核以虚线轮廓区分 |
| 不补假数据 | 绘图保留真实采样缺口；降采样仅用于显示，逐像素极值保留短尖峰；悬停读最近原始点，不跨缺口插值 |
| 保存偏好 | A/B/C、面板、分组、画中画大小/位置、波形高度随工程保存；不覆盖旧布局字段 |
| 安全输入 | 牛号、时间等输入框内的数字/字母/空格不触发动作快捷键 |
| 离线外观 | Qt QSS 样式，不需要浏览器/CSS 服务；微软 Fluent SVG 子集本地携带许可证与来源哈希 |

## 实测证据

开发工作区中的 `workspace_validation_20260906` 保存了以下证据，用户原始大数据目录未用于可写测试：

- `ui_phase2_pytest.xml`：全套 276 项自动回归通过。既有算法测试和新增界面测试一起运行，包括旧工程列数、主画面占比及画中画放大。
- `ui_native_01.json`、`ui_native_02.json`：两次实际 Windows VLC 八路播放，第二次使用内置 Python；8 路均跨小视频，已校准九轴续接、未校准不自动加载及提示均通过。
- 每轮播放中切换 6 次 A/B/C，断言参考时间、seek 代数、倍率、播放状态、原生句柄和播放器对象保持不变。
- 八路受控素材为 640×360 H.264，1 倍速；两轮首批暂停画面全部就绪约 1.01 / 0.80 秒。此数字不是八路高清 HEVC 的性能承诺。
- 原生几何测试覆盖 1280×800、1600×1000、1920×1080 请求尺寸；Windows 在全高清屏幕保留非客户区，最后一档实际客户区为 1920×1061。
- 150% DPI 的独立离屏 Qt 测试 19 项通过。覆盖布局、句柄、键盘、画中画边界、设置恢复、悬停缺口、标签 ID/选择与多轨滚动。
- `ui_preview_final`：真实牛舍录像与真实九轴副本的 A/B/C 控件截图，包含小屏幕检查。录像停在真实 11:40:00 画面；九轴没有伪造同步锚点，界面明确显示未校准。

初次真实截图试验按 create_time 粗定位后落在某一路录像范围之外，正确留空，未用旧帧充数；随后仅在测试副本保存了人工录像浏览位置，才进行双路截图。一次全套回归暴露了全局 Qt 事件过滤器与旧窗口销毁的冲突，已改成仅过滤本窗口输入控件，再次回归验证。

最终兼容性复查还隔离了旧版列数设置，避免 B 布局继承“1 列”而压缩八路画面；A 双路主画面占比可通过“更多 → 视图 → 双画面主视角宽度”调整，并独立保存。旧的打包候选已移入验证归档，不作为交付包。

C 画中画内的“放大”会切到 A 的单路大画面，仍不重载媒体，Esc 退出单路放大；重新按 C 可回到波形画中画。

## 限制和下一步确认

- 本版为界面预览，不能宣称所有电脑和所有素材都零卡顿、零错误。实际监控 PS 文件仍可能产生音轨/解码警告；八路高清与高倍率需用完整工程在目标电脑上验收。
- 窗口半透明、自由拖放分屏编辑器、自动行为识别未实现。本阶段提供可用的三种布局和画中画位置/大小设置。
- C 中被遮住的波形可通过拖动画中画查看；选择的其他视角保持准备状态，切主视角不重开文件。要降低解码负担，应在素材面板取消不需要的视角，而不是只隐藏它们。
- 真实九轴 create_time 含义仍未凭数据确证。同步确认和缺口规则不因美化界面而放宽；无录像/未复核的数据不能自动成为正常负样本。
- 图标来自 [Microsoft Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons)，固定版本与 MIT 许可证在 `assets/fluent`；样式依据 [Qt Style Sheets](https://doc.qt.io/qt-6/stylesheet.html) 的原生控件机制。
- 完整软件包仍自带 Python、Qt、VLC、FFmpeg、RapidOCR 和 PP-OCRv6 medium 权重，不要求接收者配置本地环境。压缩包与文件夹校验、离线启动自测作为最终打包后的独立验收。

建议先用这一版确认 A 的主视频/波形比例和 B/C 的切换手感，再决定是否继续扩大外观配置范围。

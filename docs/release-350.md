# COWMATA 3.5.0 纯净版

正式整合从数据归类、单日或单文件标注，到按行为与牛号构建算法数据集的流程。

## 相较 3.3 的核心升级

1. 打开更清楚、更快：确认牧场后按类别和单日加载，首份九轴与首路录像优先显示，其他检索后台继续。
2. 新增单文件模式：单九轴自动匹配当日录像，单视频配对指定九轴；支持跨盘，保存必须明确选择位置。
3. 归类与命名统一：支持混合多层目录、按九轴补视频、统一设备/耳标/视角，资源和数据集使用干净的起始时间名称。
4. 标注更可靠：修复空格焦点、零时长、排序与最新选择，恢复直接拖动，站立/躺卧/行走互斥，对齐不移动旧标签。
5. 结果与算法衔接：标签按日期归档，独立数据集构建按行为和耳标拆分、按牛划分，冲突与未知数据不当训练真值。
6. 视频与分类完善：修复时长、重复视角和人工核验恢复，优先流内时间并复核OCR；怀孕分三阶段，PPG保留占位。

## 下载

- Setup.exe：Windows 10/11 x64 安装包。
- Portable.zip：完整依赖与模型，解压运行；无需系统 Python。
- Source.zip：纯净源码、测试和文档，不含客户数据与二进制依赖。
- SHA256SUMS 与更新描述：用于下载、安装和自动更新校验。

新用户教程随包提供。原始九轴、视频和历史工程不随软件更新被改写。PPG仍未接入解析；数据集构建与测试通过不代表新算法已完成现场效果验证。

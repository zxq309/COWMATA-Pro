# COWMATA Pro 3.9.6

本版针对 3.9.5 反馈修复，保留现有管理员／操作员权限和转码参数。

## 修复

- 统一当前 1–9、A–F 标签。历史工程导入、数据集读取、模型绑定使用相同事件代码；已废弃的历史事件保留供复核，不再作为新标签或训练类别。无法明确对应的旧模型需按当前类别重训，不自动冒充新模型。
- 去除菜单字母助记键与标签键的冲突。九轴加速度、陀螺仪、磁力计的 X/Y/Z 分轴显示。
- 视频草稿与待复核标签可以直接打开已有证据截图，查看不自动确认真值；未对齐时也可查看已保存图片。
- 常规归类采用 Windows 系统文件夹选择器，支持 Ctrl/Shift 多选。重新选择替换当前目录，追加目录明确追加，清空目录移除当前选择；取消选择保留原选择。
- 多视角目录在源文件已移动、目录为空时仍显示；恢复任务不再把旧任务的行混入新目录。空闲关闭子窗口会重置选择，运行中关闭仅隐藏，后台继续。
- 管理员名册兼容 UTF-8、UTF-8 BOM 和 GB18030/GBK，保留严格字段校验。同步台账上传器 1.4.0 的授权编码修复和部署模块；管理员支持独立并发在线会话，授权仍以服务器为准，本地复制 CSV 不能取得权限。

## 使用

常规归类：选择牧场 → 重新选择目录（可多选）→ 勾选视角 → 一键归类。需要更多总目录时用“追加目录”。已完成的任务记录仍保存到牧场中；关闭空闲窗口清空的是本次表单，不删除已归类成果。

原始录像归类与常规归类共用校验复制函数和安全提交路径。本版不改变原盘只读、MP4 转码参数或任务暂存语义。转码完成后的文件搬运与解码耗时是两个独立阶段。

本地提供源码、便携、安装三种包；GitHub Release 仅附安装包。完整验证范围见 [验证记录](validation-396.md)。

提示信息说明与处理办法

COWMATA Pro 4.4.3 · 软件里出现的提示是什么意思、为什么出现、下一步怎么做

怎么看提示三条最常问确认真值记录动作对齐播放素材与核验协作派包下载 / 归类 / 台账保存与更新

先看这里：提示出现在哪里

  • 顶部横幅（工程路径下方的一行）和窗口最底部状态栏：最近一次操作的结果或原因。
  • “动作起止”按钮下方的小字：正在记录哪个动作、确认失败的具体原因。
  • 弹出窗口：需要你选择的事情，例如“还不能确认真值 → 去核验该录像”。
  • 想看刚才所有提示：主界面“更多 → 加载记录…”。

两条原则：① 软件不会改写原始九轴 JSON 和录像；② 操作失败时，已记录的视频草稿和标注都会保留，照提示处理后再点一次即可。

三条最常被问到的提示

视频画面/时间映射尚未确认到位，请回看并更新证据

含义：把一条标注“确认为真值”需要同时满足两个条件：① 画面到位（视频暂停在动作上，画面下方出现“精确暂停帧 … 原片”）；② 这段录像的时间已核验（软件确认录像画面上的时间和九轴时间对得上）。缺任何一个都会出现这条提示。等待只能解决①，解决不了②。

4.4.3 起的变化：这条笼统提示改为直接写出原因，例如“视角03 的录像《2026-09-04_21-00-00.mp4》时间还没有核验（待复核）”，并弹出“去核验该录像”按钮。如果视频不在这条动作上，软件会先自动跳到动作开头。同时，非大华品牌录像机的原始码流现在也会读取录像机自带时钟自动核验（以前一直停在“待复核”，这正是“等画面到位后仍然无法确认”的主要原因），需要人工核验的录像大幅减少。

怎么做：

  1. 在右侧标注列表双击这条草稿，视频跳到动作开头。
  2. 等画面下方出现“精确暂停帧 … 原片”。
  3. 点 操作 → 确认真值（或 标注 → 确认为真值）。
  4. 如果弹出“还不能确认真值”并写着“时间还没有核验”：点 去核验该录像，按 录像时间核验步骤 在开头和结尾各确认一个读数，保存后回到动作再确认。
请回看对应动作并等画面到位；旧标注需先建立视频草稿

含义：这是点“补充证据”时的提示。“补充证据”只对视频草稿有效；旧标注（导入的旧工程、协作回传、模型直接生成的标签）没有视频草稿，所以以前会被拒绝；另一个原因是视频还没停在这条动作上，或画面还没到位。

4.4.3 起的变化：旧标注不再需要“建立视频草稿”：选中旧标注 → 双击回到动作 → 等画面到位 → 直接点 确认真值，软件一步完成（保留原编号、原备注，可撤销）。对草稿点“补充证据”时，如果视频不在动作上，软件会先自动跳过去，提示你等画面到位后再点一次。

怎么做：旧标注 → 双击 → 等画面 → 确认真值；视频草稿 → 双击 → 等画面 → 补充证据。

请先等待视频通过可读性检查，再核验时间

含义：在“核验”（素材索引）窗口里，你选中的行不是一段可以核验的录像。常见两种情况：选中了九轴 JSON 行（JSON 不需要核验时间）；或选中的录像还是未索引（还没读出时长，不能核验）。

4.4.3 起的变化：“核验”窗口默认只显示当前记录用到的录像，需要核验时间的录像标成黄色并排在最前；上方可切换“需要核验时间的录像 / 全部录像 / 全部素材”；“定位当前画面录像”一键选中主视角正在播放的那段；双击黄色行直接开始核验。

怎么做：左侧 核验 → 选中黄色行 → 核验所选视频时间。未索引的录像：选中后点“重新建立所选视频索引”，或先在左侧选中对应九轴记录，等后台读出时长后再核验。

录像时间核验步骤（一次做完整段）

  1. 点 读取开头画面。软件会按文件名时间预填“画面读数”。
  2. 对照画面上的时间水印逐字核对（包括日期）；不一致就改成画面上看到的时间。
  3. 点 确认当前读数。
  4. 点 读取结尾画面，重复第 2、3 步。
  5. 窗口下方显示“第 x 秒到第 y 秒之间算已核验（约占全片 100%）”后，点 保存。

为什么要两个读数：两个读数之间的录像才算“已核验”，只核一个点只能粗定位。开头、结尾各一个，整段录像上的标注就都能确认。时间水印看不清时，可先框选水印区域再点“识别框选区域 / 四角”。

# 3.1.0a4：简洁输出与独立历史回看

## 本步骤范围

默认只保存一个标注 JSON，不再自动套一层导出目录并同时输出七个文件。保留全部人工标签、草稿、来源 SHA-256、母文件时间坐标、校准版本、相关录像索引快照。训练/兼容格式明确独立为可选批量导出，先检查真值门控再创建输出目录。

标注 JSON 可放任意目录，不需复刻录像的时间目录。完整标注文件引用原始九轴；可选的小片段文件额外内置所选原始二进制帧（v0/v1/v2），不重采样，保留实际缺口和母文件偏移。跨片段边缘的标签保留完整原边界，绝不把裁剪边缘变成人工事件边界。覆盖同一文件保留一份 .bak；原件及其他来源的标注拒绝覆盖。

独立历史窗口可在不打开当前标注工程的情况下回看；读取索引使用 SQLite mode=ro，不申请写锁、不创建新索引、不覆盖当前工程。点击标签定位波形和多视角录像；沿参考时间自动换下一小视频；片段结束暂停。支持观察/网格布局、主路优先预览和单视角放大。加载、身份核验和导出在后台进行。源录像变化时暂停并隐藏失效画面。

主工作台打开的历史窗口在关闭/再开时复用同一个最多 9 个播放器的池；不会每份标签另加八个解码器。主窗口进入历史时先暂停当前视频，退出软件时关闭历史资源。独立命令行历史窗口则在关闭时结束。

工程搬家后重新选择根目录。已索引的重命名文件按内容身份找回；无索引但原相对路径存在时，快照仍可使用，搬家后校验 SHA-256。保留当时相机校准版本；未知采集起点不靠文件名/create_time 猜配。

## 明确边界

- 本步历史窗口只读，不自动将旧标签覆盖到当前工程。继续修改当前工程用原有工作台；导入旧单视频工程仍需明确确认来源。
- 旧 JSON 工程可读；来源身份/校准缺失只展示标签，不能自动恢复未知对应关系。没有来源信息的独立 CSV 或旧小片段不能凭空推断母录像。
- 完整标注 JSON 不复制整份九轴；原件丢失仍可看标签，不能恢复原波形。小片段内置九轴，不内置视频，不伪装温度/活动量的时间轴。
- 若原录像已覆盖、删除或全量重命名且索引也丢失，需恢复原件或先在主窗口重新建立索引。查不到录像不等于负样本。
- 单点/外推校准仅粗定位。多视角时间映射仍需现场校准，导出不会创建新锚点。
- 20260906 五个新事件模型的隔离兼容环境已在开发目录准备，但本 a4 包未接入预测 UI，未声称模型输出一致性/正确率已验收。后续按版本包、后台候选、人审真值和参考环境对照分步接入；旧人工/模型辅助源代码保留。

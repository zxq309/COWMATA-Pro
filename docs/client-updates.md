## 3.9.2 及 3.8+ 旧版恢复

如旧版无法检查、下载或安装，请从 [最新发布](https://github.com/zxq309/COWMATA-Pro/releases/latest) 下载 Setup，保存关闭旧版后运行，选择旧程序目录即可原位升级。支持 3.8.0 及以上安装版和便携版；便携版会转为安装版。正常工作的 3.9 客户端也可在“帮助 → 关于 → 版本与更新”直接升级。

# 安装与更新

软件启动后在后台检查 [COWMATA Pro 最新发行版](https://github.com/zxq309/COWMATA-Pro/releases/latest)。断网或检查失败不会阻挡标注。在“帮助 → 关于 → 版本与更新”可以重新检查、下载和续传。

下载完成后，正常保存并关闭工程，安装版会校验、升级并重新打开。校验或安装失败时保留原版，替换或注册失败时回滚。

## 旧版更新报错

如果旧版显示 **Update URL outside the configured repository** 或 **Refusing a broad installation target**，请从最新发行版下载 **Setup.exe**，运行一次。安装器自动定位已注册的 COWMATA 目录；确认位置、保存标注并关闭旧版后，即可原位置升级。安装器自带兼容升级程序，不依赖旧客户端的更新代码，也不需要修改配置文件。

3.8.0 及之前安装在盘符下一级目录的客户端也可用此方式升级。3.8.1 支持这种安装位置，后续恢复正常更新。前者是旧地址校验，后者是旧安装路径检查；都发生在旧客户端交接安装任务之前。这类客户端需要先运行一次新版安装包。

源码和便携副本不会被当作安装版覆盖。便携版解压到新目录，运行其中的 COWMATA.exe。更新不迁移原始数据、标签和个人设置；安装目录中的非软件文件会阻止替换并被保留。

公开发行版仅提供源码 ZIP、便携 ZIP、安装 EXE。校验信息放在发行说明中，由客户端读取，无需第四个下载文件。

# COWMATA Pro™ 3.8.0

顶部菜单按文件、数据准备、标注与复核、数据集构建、健康与繁殖、帮助排列。下载和归类放在数据准备首层，自动候选进入标注工作区；原有逐项算法检查、同步、协作与兼容导出保留在相应菜单内。

工作子窗口可独立最小化、恢复及从菜单重新唤回。关闭主窗口时保留任务停止与未保存复核的检查。实时归类和数据集记录刷新保持选中行，减少重建表格。

便携运行依赖经过原生依赖审计，剔除未使用的 Qt 模块、QML、类型存根、调试及链接文件，保留运行库、五个注册模型及其全部模型文件。五个模型在精简环境中实跑，与原环境输出比对一致；这不等于预测准确率验证。

图文教程随源码、便携包与安装包提供：打开帮助中的新手图文教程。截图来自实际软件和受控演示数据。健康与繁殖中尚未接入模型的功能明确注明状态，没有生成占位预测。

Release 附件只有源码 ZIP、便携 ZIP、安装 EXE。3.7 及更早版本请直接下载新安装包或完整便携包升级；3.8 的更新客户端同时支持旧清单和发布说明内的校验信息。

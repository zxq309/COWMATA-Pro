# COWMATA Pro 3.9.8

原始录像归类支持一键“继续上次归类”：恢复原任务与映射，从未完成或失败的片段继续；已完成且身份与校验证明未变化的文件直接复用，不重复转码、复制或整文件读盘。与常规数据归类共用已验证归档复用判断。

## 本次修复

- 修复这批大华录像 PCM 音频时间戳回退导致 AAC 非单调 DTS、MP4 写入失败的问题。只有原始帧序号与计数可证明连续时才恢复时钟，保留已测得的视频时间间隔及音频初始偏移；缺帧或无法证明的时钟不猜测。
- 兼容的整段 H.264 / H.265 优先保留视频码流封装 MP4。原生时间间隔存在小幅变化时保留实际变化，不再据中位帧率重建，也不会按错误的解封装时长截断整段录像。
- 快速封装核对容器、视频帧数、时间线和边界可解码性；编码回退仍做完整解码。实际异常样本另行完成了整段解码和全部视频画面码流哈希比对。
- 单原盘读取受控排队，转换可与后续读取重叠，转换并发由资源预算限制；任务总览如实区分处理与排队，并非 20 个视角同时抢占硬盘。
- 复用成品显示为复用，不把成品总大小计入实际传输速度。
- 派包扫描支持从健康类别目录定位牧场根目录，保留每个包独立类别、日期和全量录像视角规则。

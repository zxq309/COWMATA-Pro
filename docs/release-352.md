# COWMATA 3.5.2：视频规范整理

本版在 3.5.1 上更新数据归类。安装包与便携包均包含运行环境，无需安装 Python；原 3.5.1 交付保留。

## 目录与时间规则

视频保存为 `牧场/类别/Video/2026-08-17/视角01/2026-08-17_00-00-00.mp4`。视角01至视角08各自为独立目录，不绑定设备号、牛耳标或现场记号。同视角、同一秒但内容不同的文件追加 `__001` 等序号，不覆盖；完全相同内容避免重复归档。

视频文件名采用实际开始帧画面上的完整日期和时间，按北京时间归档。首帧可读就使用首帧，不采样中段、尾段，也不用文件创建时间或旧文件名猜日期。海康已支持的像素时间戳布局优先走专用识别器，重封装后没有流内时钟也适用；不适用时读取同一首帧的通用 OCR。

这里只确认命名所用的画面读数，不宣称全录像连续同步已核验。跨午夜录像按开始日期放置，整段连续性、实际结束时间和跨日播放关系由标注阶段核验。

## 使用步骤

1. 打开「数据整理 → 数据归类」。九轴、标签已归类时，选择「九轴已归类，仅补整理视频」并指定现有类别工程。两者均未整理时，选择「九轴与视频一起整理」。
2. 点击「添加录像目录」，选择包含所有录像的大目录。递归识别其中的视角01～视角08；不明确的来源需要在来源表指定视角。九轴来源单独添加；「添加混合大目录」用于保留非视频的混合素材。
3. 日期可留空。仅补视频时按已有九轴的日期收录全天录像，不要求与某条九轴的分钟、秒区间重叠，不关联单头牛。日期有多种实验类别时，按已确认的类别分批处理。
4. 选择保存方式与视频并行数，默认4，可选1～8。机械盘可从2开始。点击「并行识别首帧并预览」，每完成一项就出现在列表中；此阶段尚不移动或删除文件。
5. 双击视频列表行，核对开始帧、时间和目标文件名。选择记录后，下方完整信息区显示来源与目标全路径、开始时间和处理说明；也可点击「查看完整审核记录」在大窗口核对。点击预览结果上方固定显示的「一键执行归类」后逐条显示「已归档」或「已删除」。

## 清理与异常

单独通过「添加录像目录/文件」指定的来源中，确认的文本、图片、音频、文档或空文件会在执行时删除，执行按钮旁显示永久删除数量。混合来源中的非视频保留。九轴 JSON、标签、CSV、数据库、Motion/PPG、标注工程等受保护文件保留。

有视频后缀并不代表是录像：通过内容识别和解码检查。损坏、未下载完整、首帧读不清、视角不明确或整理前后内容改变的文件保留原处，列表显示「待确认」，其他正常文件继续。默认勾选「仅归档通过校验项」。待确认项可导出报告后逐项核对。

同盘移动不重新编码或复制视频数据；跨盘采用校验复制并保留来源。任务记录和识别缓存放在素材目录之外。执行中可暂停，已完成项保留；继续任务会复核身份与目标文件。识别预览被暂停后，可重新点击预览复用未变化文件的识别缓存。

## 本机验证范围

两份256 MiB真实录像副本，两路并行首次首帧识别共约24.6秒。Windows界面测试中，一份256 MiB录像与一份8秒重封装录像，两路并行预览约27.8秒，执行同盘归档和非视频删除约2.0秒；两条视频均读出画面上的2026-08-04 23:09:27。已验证重封装录像无流内时钟、结果逐条显示、首帧核查、损坏文件保留及原九轴/标签完整性。

以上为本机有限样本，速度受磁盘、并行数、分辨率和OCR布局影响。未对用户海量原始目录执行整批迁移。原有通用标注教程可继续阅读，但其中旧版视频整理说明以本指南为准。

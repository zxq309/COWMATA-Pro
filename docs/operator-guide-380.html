先看这里

  1. 安装版：打开 Setup，下一步、同意许可、选择位置、安装，完成后从桌面打开 COWMATA Pro™。便携版：解压整个 ZIP，打开文件夹内的 COWMATA.exe。
  2. 已有工程直接打开；新数据先下载或归类。
  3. 工作窗口可以独立最小化、恢复。Windows 合并任务栏按钮时，从窗口预览中选择对应窗口。
  4. 截图使用演示数据；测试同步与演示标签不代表牧场真值。

1　准备数据

  1. 端侧下载：选择牧场、服务器、设备、时间范围，再点开始。自动/定时下载需保持软件运行。
  2. 数据归类：先选牧场与类别，再选视频总目录、勾选视角，点一键归类。已归类材料复用。
  3. 暂停后继续原任务。实时记录随处理更新；Excel 直接打开 CSV 是当前快照。

2　标注与复核

  1. 人工标注：选标签，在动作开始和结束处按对应快捷键，再保存。点事件只记录一次。
  2. 自动候选：打开完整 V2 九轴并核对牛号，选择支持的模型运行；看录像后接受、调整或排除。空结果不代表没有事件。
  3. 复核已有标签：选记录、改类型/边界/备注、保存到原标签文件，记录编号保持不变。
  4. Ctrl/Shift 多选后可以批量修改、删除；Ctrl+Z 撤销。点事件与区间需要逐条核对边界。
  5. 已有标签无需重新建立草稿。确认真值用于具备同步、牛号和到位录像证据的视频草稿。

3　看清视频和波形

  1. 观察用于重点看主画面，多视角用于同时对照，波形用于精看信号。
  2. 波形滚轮缩放、拖选区间；角速度三轴分行。显示完整九轴的快捷键为 Ctrl+Shift+F；F 留给助产。
  3. 同步先找录像与信号中的同一个动作。未核实同步时保留待复核状态。
  4. 证据截图需要有效原片帧；补充证据和截图不会自动证明整段动作。

4　生成完整数据集

  1. 从数据集构建选择任务，填写来源和数据集总目录，再点开始新版本。
  2. 按时间戳保存版本，并按行为、Motion/PPG、Raw/Label 配对。文件名保留设备、耳标、现场标记和采集时间。
  3. 每份文件都有状态与耗时。暂停后继续当前版本；来源或标签变化后开始新版本。
  4. 未标注记录明确保留为 Unlabeled/Context，不当作负样本。

5　健康与繁殖

  1. 保留产犊、发情、怀孕三个阶段及疫病入口。
  2. 本次现有健康项目尚未注册可执行模型，已实测其入口、状态提示与返回标注；没有进行预测准确率验证。
  3. 已注册的五个事件模型已单独实跑并与旧版输出比较，不将事件候选当成健康结论。

6　帮助与升级

  1. 帮助中可打开本教程或查看版本信息。网络更新失败时仍可进入软件。
  2. 3.7 及更早版本请直接下载 3.8 安装包或完整便携 ZIP 升级。3.8 支持仅有三个附件的后续 Release。

3.9.6 · 每日协作流程

什么时候下载，什么时候派包

上传器 → 数据准备／端侧数据下载 → 数据归类 → 标注与复核／多人协作

  1. 先在上传器核对并同步三份 CSV。下载器每轮重新读取台账，按监测目的、佩戴时段和牛号决定健康类别。
  2. 五项必填完整且九轴、温度有效才下载三类数据；非产犊记录的“/”算已填写，产犊记录必须是真实起止时间。缺项暂存待核对，补齐后下一轮再检查。
  3. 下载结束后，按数据日期归类录像到牧场根目录的“录像／日期／视角”。三类 JSON 保持在健康类别内。
  4. 派包默认选择历史日期，核验下载完成记录、CSV 是否变化、Motion／PPG／Temp 是否有效齐全，以及所选视角录像是否覆盖采集时段。任一不符会列明原因并阻止派发。
  5. ZIP 固定本次清单，不会随着明天的数据自动改变。已派数据默认不重复勾选；新增记录显示“新增资料待补派”。容量仅提示，不设硬上限。
牧场根目录/
├─ 产犊/、发情/、怀孕/孕早期/、怀孕/孕中期/、怀孕/孕晚期/…
│  ├─ Motion/日期/设备-牛号-现场记号/时间戳.json
│  ├─ PPG/日期/设备-牛号-现场记号/时间戳.json
│  ├─ Temp/日期/设备-牛号-现场记号/时间戳.json
│  └─ 标注工程/数据类型/日期/设备-牛号-现场记号/时间戳.标注.json
├─ 录像/日期/视角01～20/时间戳.mp4
└─ 科牧特_协作标注/原始数据包、标注数据包、派发记录、接收记录
有标签不等于标注完成。草稿或部分标注仍可继续；已“完成本份”的全部主记录默认转入复核任务。资料完整性核验不等于已经完成人工时间对齐，也不证明模型预测准确率。
3.9.6 · 多人协作

派发、打开、回传与接收

标注与复核 > 多人协作

  1. 派发原始数据包：选择牧场、健康类别、标注或复核任务，扫描后选日期与视角，设置包数并预览。每个设备日期条目保持完整，按条目数再按记录量均分。确认后生成带任务编号与分包号的 ZIP。
  2. 打开任务：接收人使用“文件 > 打开协作原始数据包”，选择解包位置。软件校验后恢复同样的目录树，再打开对应健康类别与日期。不要手工打散文件。
  3. 生成标注数据包：先保存工程，再选择此任务的牧场根目录。生成的 ZIP 只包含标注及其证据图，沿用任务编号，增加本次回传编号。
  4. 接收标注数据包：选择原牧场与回传 ZIP（可多选）。先校验任务身份、目录、原始文件 SHA-256、设备牛号、健康类别、当前标签代码和时间范围，再写入正确的标注工程位置。
  5. 相同内容跳过；存在不同内容时整包进入冲突待核对并生成报告，保留原标注。回传草稿仍是草稿，不自动进入训练真值。

命名示例：牧场_产犊_2026-09-17至2026-09-18_标注_任务号_P001_原始.zip。复核包带已有标签；回传包带同一任务编号及独立回传编号。

请保留“科牧特_协作标注／派发记录”，接收端依靠它确认授权范围。旧目录可通过“数据准备 > 统一牧场录像目录”迁移；软件会检查占用、保留元数据备份并更新录像引用。

先完成一次完整工作流程

帮助 > 新手图文教程…

开始前：安装包完成安装；备好管理员或操作员的登录信息。

  1. 先阅读“激活与账号”；管理员与操作员均可查看完整教程。
  2. 准备台账和数据，完成下载或视频归类。
  3. 打开工程，选择日期、牛只与记录，再选择当前要观察的视角。
  4. 核对录像和传感器时间，建立标签、查看证据，再保存。
  5. 管理员按任务导出数据集、训练或导入模型；操作员完成标注并提交成果。

完成后：得到可重新打开的工程与标签；分析结果通过独立输出目录交付。

  • 练习使用副本。本文中的示例标签用于说明操作，不能作为额外的训练真值。

03 · 所有人

管理员登录与操作员首次激活

启动 COWMATA Pro

开始前：联网；管理员备好账号和密码，操作员另需管理员发放的授权码。

  1. 在登录身份中选择“管理员”或“操作员”。
  2. 管理员填写账号和密码登录，无需授权码；可以在其他电脑使用同一管理员账号。
  3. 操作员首次登录填写账号、密码和授权码；本机激活后，再次登录可填写账号与密码，授权码留空。
  4. “保存密码”“自动登录”默认均不勾选。只勾选保存密码，下次回填后仍需点击登录；明确勾选自动登录，才会在下次启动时自动登录。
  5. 忘记密码时点击“忘记密码”；管理员维护电脑可查看或修改本机账号 CSV，其他电脑联系管理员。密码修改或授权撤销后重新核验。

完成后：成功进入与账号角色对应的工作界面。

  • 管理员授权码为空；操作员未使用的授权码可留待分发，首次激活后绑定当前设备。
  • 不要把真实密码或授权码放入工程、截图、教程或公开发布包。
  • 保存的密码使用 Windows DPAPI 加密，仅当前 Windows 用户可读取；不要在共用电脑上勾选自动登录。
04 · 管理员

管理员批量发放与撤销账号

账号 > 账号管理…

开始前：已使用唯一管理员账号登录。

  1. 在“生成数量”设置需要的账号数，点击“批量生成”。
  2. 选中要分发的账号行，点击“复制所选”，仅将对应一行交给指定使用者。
  3. 账号表保留“账号、密码、授权码”三列；管理员授权码为空，操作员未用过的授权码可按需分发。
  4. 需要撤销时，选择对应账号并点击“删除所选”，核对账号后确认。唯一管理员不能在此删除。
  5. 在管理员维护电脑可使用“打开本机 CSV”；关闭旧表格窗口后重新打开，避免旧缓存覆盖三列表。

完成后：操作员使用自己的账号；被删除账号在服务核验后失去访问权限。

  • 不要录制或公开分享真实三列账号表。
  • “锁定当前账号”用于临时离开；“退出登录”保留本机授权；“清除此设备自动登录”删除本机自动登录记录。
  • 服务器连接失败时不能新激活或启动；已登录会话有有限离线宽限，持续核验失败将保存并安全退出。

按三份台账选择性下载

数据准备 > 端侧数据下载…

开始前：准备扬大测试设备台账.csv、扬大产犊登记汇总.csv、样本试验台账.csv；服务器连接可用。

  1. 重新读取台账，查看“可下载、待补全、不下载”的记录及原因。
  2. 核对产犊开始、产犊结束、九轴、脉搏、温度五列均有值。

同时归类多个视频总目录

数据准备 > 数据归类… > 常规数据归类

开始前：正常可播放的视频；已确定牧场、类别和复制/移动方式。

  1. 选择牧场目录、类别和归类方式。
  2. 点击“重新选择目录…”打开 Windows 系统文件夹选择器；按 Ctrl 或 Shift 可选择多个总目录。继续增加来源时点击“追加目录…”，选错时点击“清空目录”。
  3. 等待后台逐步列出各目录视角，勾选要处理的项目并核对归档视角。
  4. 点击“一键归类”，在状态和记录中查看正在处理、完成和异常项。
  5. 需要中止时点击暂停；保留同一任务设置后继续。

完成后：按类别、日期、视角输出时间戳视频。

  • 所有目录共用有界并发，增加目录不会无限增加拷贝线程。
  • “同盘移动，跨盘复制”会在同一磁盘移动正常视频；需要保留原件时选择复制。
  • 界面注明：确认全程黑屏、空录像或损坏后会删除原文件。练习须使用副本。

将原始录像转为标准 MP4

数据准备 > 数据归类… > 原始录像转码与归类

开始前：可读取的 DAV/DHAV 文件、目录或录像机原盘。

  1. 选择文件/目录来源；录像机原盘使用盘符下拉列表和“刷新原盘”。
  2. 选择输出牧场与类别；按需填写北京时间范围和跨午夜按天拆分。
  3. 点击“扫描原始录像”。Channel 01–20 自动对应视角01–20；无来源的视角不接入。
  4. 用“核对已选通道缩略图”确认通道内容。
  5. 点击“开始转码并归类”，完成后打开归类目录并检查任务记录。

完成后：输出路径形如“牧场/产犊/Video/日期/视角01/日期_时-分-秒.mp4”。

  • 原始录像盘只读，不格式化。
  • “选择外部 JSON 目录…”用于另外合并传感器记录；仅转码视频无需选择，牧场已有 JSON 保留。
  • 暂停后可恢复上次视频任务；能保留编码的片段采用封装，其他片段按需要转码。

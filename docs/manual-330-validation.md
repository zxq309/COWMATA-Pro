# 图文教程 3.3.0：截图与验证范围

本手册按准备数据、审查归类、标注保存、复核导出排列，32页，每页3个短步骤，含PDF书签。全部截图来自当前源码实际运行的Qt控件或3.3.0候选安装向导，不复用旧界面图，不用生成图模拟功能。

原始牛舍录像仅只读截取两段30秒短片到隔离测试目录。九轴、目录身份、孕晚期分类和演示标签是测试数据，不代表真实牛只绑定、孕期判断或行为真值。两路短片的首帧日期时间人工核对，视频播放进度与参考时间分别保留，不靠文件名或截取命令推定时钟。

## 可复现资料

- 编辑文字：`quick-start-illustrated.source.json`，只引用仓库内截图文件名。
- 已检查截图：`assets/screenshots/manual-330/`。
- 当前Qt捕获脚本：`scripts/capture_quick_start_330.py`。必须显式提供源码、组件、授权录像和隔离工作目录。
- PDF生成器：`scripts/build_quick_start_pdf.py`。默认读取上述文字和截图，输出PDF、等价Markdown及SHA-256清单；不依赖本机临时目录。
- 生成命令：`python scripts/build_quick_start_pdf.py`，需要ReportLab和可用中文字体；可用`--font`与`--bold-font`指定字体。
- PDF质检：Poppler全页渲染，PyPDF检查32页与32个书签、每页标题和所有短步骤均可提取；逐页目检截图比例、文字、页码与留白。第12、22页采用主图77% / 菜单23%，避免日志和导出界面过小。

验证事实见`manual-330-capture-evidence.json`；截图与PDF的SHA见`quick-start-illustrated.manifest.json`。哈希清单在每次重建时刷新，避免文档和截图内容不同步。

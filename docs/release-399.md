# COWMATA Pro 3.9.9

## 录像归类速度与容量

- 默认使用“快速原码流封装”。兼容的 H.264/HEVC 视频只改封装，不重新编码，保留原始视频码流和分辨率。
- 录像机把一个整点前的几秒写入上一段时，3.9.9 使用输入侧边界定位后继续封装原码流。旧逻辑会把整段录像当作中间裁剪而重新编码，这是长时间 CPU 占用的主要来源。
- 音频时间轴出现短暂倒退时，先用 `aresample=async=1` 修复音频时钟；视频不重新编码。只有视频包本身不满足 MP4 时间轴时才进入编码兜底。
- 新增可选“H.265 节省空间”模式。该模式使用可验证的 Intel QSV/NVIDIA HEVC 硬件编码器，保持原分辨率；没有可用硬件编码器时直接提示，不会悄悄回退到慢速 CPU 编码。

## 并行归类

- 20 个视角全部进入并行任务调度，不再固定只有 2 个视角运行。
- 原始机械盘读取保持单读保护，避免磁头争用；读取完成后的封装、校验和归档重叠执行。界面会区分“已排队”和“处理中”，不把排队误报成已经读盘。
- 已完成且身份、哈希未变化的成品继续直接复用；暂停后再次继续不会重复转码。

## 适用范围

默认模式优先保证速度和画面一致性，输出文件大小接近原始视频。需要减少容量时手动选择 H.265 模式；它会重新编码，因此速度会低于原码流封装，压缩比例取决于原始码流，软件不会承诺固定百分比。

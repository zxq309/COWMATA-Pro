# COWMATA Pro 3.9.4

- 原始录像扫描后，Channel 01–20 自动填入同号视角，无需逐行选择。列表按通道号排序；未知或有歧义的来源保留待选，缺失通道不会错位补入。
- 直接选择牧场和类别，视频按 `牧场/类别/Video/YYYY-MM-DD/视角01–20/YYYY-MM-DD_HH-MM-SS.mp4` 保存，按录像真实日期自动创建 20 个视角目录；不生成占位视频。跨午夜仍可按天拆分。
- 默认只转码和归类视频，已有 Motion/PPG/Temp 不需要再次选择。原“附加 JSON”改为默认关闭的“同时导入外部传感器 JSON（可选）”，只复制传感器 JSON，不处理夹带的视频。
- 修复把当前牧场、类别或 Motion 目录当作附加来源导致“输出、原始来源和任务暂存目录必须相互独立”的错误；已有数据保留原位置，不重复归类。原码流与任务缓存的隔离校验继续保留。
- 修复 Windows 临时目录名 `Temp` 干扰传感器分类：优先识别九轴、PPG 内容及最近的传感器目录，避免把普通下载误当温度。
- 延续 3.9.3 的盘符直接选择、后台扫描、紧凑表格和保存退出更新修复。录制盘只读，保留原始录像、温度格式、共享标签和模型输入约定。

录像机时间用于视频命名；不代表已经校准到传感器时间。导入后的人工同步和复核功能继续可用。

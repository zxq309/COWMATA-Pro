# COWMATA Annotator 3.5.1

- 数据归类的起止日期支持日历选择，也可留空自动读取日期。
- 牧场目录支持选择完整目录，不预设牧场名称；仅整理视频时可选类别和孕期。
- 已整理九轴与标签的牧场作为目标，从另一个混合大目录递归筛选视频，跳过非视频文件。录像继续按实际开始时间戳命名；日期筛选保留跨午夜的覆盖录像。
- 站立、躺卧、行走在记录起点时就检查已有状态区间；有冲突的结束点不会被锁定，可重新定位结束。点事件仍可单独记录。
- 启动更新发生网络或下载异常时，可点击“进入软件（稍后更新）”；安装包完整性检查保留，失败不执行安装。
- 复制支持有界读写流水线、机械盘批量缓冲和校验后续传；同盘移动直接改目录项。跨盘仍复制并保留来源，与原版本保存方式一致。
- 更新完整图文操作教程和本版新增界面截图。

本版没有激活码、核验码或账号登录要求。源码、便携包和安装包均可离线使用。
仓库可见性按本次决定保持公开。本版安装包与更新清单通过 GitHub Releases 分发。

迁移策略借鉴 [FastCopy 官方公开说明](https://fastcopy.jp/help/fastcopy_cn.htm) 中按设备选择并行读写或批量缓冲的思路，由本项目独立实现。没有捆绑 FastCopy，也不声称达到其全部 Direct I/O、Overlapped I/O 或 Pro 功能。实际速度取决于存储设备、缓存、文件大小和校验成本。

## 更新与安装验收

启动检查的“已是最新”“存在更新”“网络失败”三分支用实际Qt窗口验证，网络和安装启动边界受控替代；需更新或检查失败时正常工作台均未开放。损坏下载重试、回滚失败保护、真实独立更新进程互斥另有回归。

独立旧版3.2.1更新器已实际执行3.3候选安装器的解包、全文件哈希、私有Python/Qt导入、目录替换与旧文件清理，新启动器版本为3.3.0.0。此项注册和重启边界替代，未改现用安装；最终安装器另执行真实注册、新装、快捷方式和卸载检查。第一次升级仍由旧更新器执行，新互斥/恢复规则从3.3安装后生效。

发行前固定代码和手册，检查安装包SHA、包内清单、新装/卸载、旧更新器迁移及GitHub四组CI。**最终安装包的机器可读验收记录随同版本附件发布为 COWMATA-3.3.0-Delivery-Checks.json**；它在最终EXE生成后记录哈希和实测结果，避免文档内嵌自身安装包哈希造成循环。安装器、更新描述文件、SHA与验收记录一致后才公开最新版。

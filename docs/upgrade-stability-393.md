# 3.9.3 升级兼容与稳定性

本版继承3.9.2的官方GitHub限流回退、TLS/超时重试、断点续传、便携ZIP更新、独立更新进程和失败回滚，并针对2026-09-16的公开历史包实测增加两项修复。

## 已修复

- 15个早期可执行包（3.1.0-rc.1至3.4.3，10个不同清单）缺少version。3.9.3仅通过已核验官方清单的精确SHA-256读取对应版本，不执行旧代码、不根据文件夹名推断、不改写原清单。未知或被改写的无版本清单仍拒绝升级。
- 最早RC启动器不支持进程检查参数。安装器和便携修复流程优先使用随新版提供的独立启动器检查目标目录中的进程，避免为了探测而启动旧界面。

原位替换仍先验证新包、完成运行库导入检查、确认旧程序关闭，再交换目录。注册失败回滚；发现安装目录混有未归属软件的用户文件则停止并保留原件。

## 升级方法与边界

- 3.9.2安装版和便携版可通过“帮助→关于→版本与更新”检查本次Release，也可下载完整安装包或便携ZIP。
- 旧更新器被旧仓库协议、缺失安装标识或网络错误阻断时，下载本版Setup并选择原软件目录；或从新版便携目录启动“修复旧版更新.cmd”，选择旧版COWMATA.exe和完整新版Portable.zip。
- 便携ZIP修复会将旧安装副本转为便携副本；安装器升级会建立新版安装注册。两种行为不能混称。
- 发布新版不会修改已分发旧客户端内的更新代码。旧客户端没有自动更新功能或旧协议不兼容时，不能宣称其原版自动更新已全部修复。
- 源码包不是可执行客户端，不能计为客户端升级成功。测试结果区分原版自动更新、新版安装器原位升级、便携ZIP修复。

历史测试基线：67个公开软件包校验通过，其中Pro旧可执行包35个，升级到3.9.2时原位20成功/15失败，原版自动更新5成功/30阻断。以上是3.9.2基线，不代表3.9.3结果。本版的实测结果见本次Release说明和随交付目录保存的升级验收记录。

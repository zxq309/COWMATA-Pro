# 3.6.0：数据归类与端侧数据下载

工具菜单统一提供“数据归类”和“端侧数据下载”。

- 数据归类采用单窗口流程，支持 JSON 与视频一起归类、已有 JSON 补充视频两种场景。
- 已归类且文件身份未变化的材料直接复用，不重复 OCR、复制或整文件哈希；新增、缺失或变化的文件才处理。
- 暂停后继续原任务，避免失败的新任务遮住原有断点。复制过程支持临时文件校验续传。
- 修复 MPEG-PS 录像探测超时、OCR 硬限时取消及时间标点丢失导致的漏归；视频日期超出九轴日期也照常归类。
- 实时 CSV 逐条记录状态和耗时；Excel 独占文件时保留完整日志并切换可写副本。
- Motion、PPG 中只保留 JSON，Video 中只保留视频；附属文件可追溯迁移到材料目录之外。
- 端侧下载提供手动、自动、定时三种模式，支持 Motion/PPG、重复识别、失败重试、迟上传补下与多牧场配置。
- 标注工具退出时先停止下载线程，再执行原有保存退出流程。

发行包包含离线运行环境、视频解码器和模型。包中不携带本机密钥、个人配置、下载索引、日志、缓存或牧场试验数据。
归类使用的推断时间仍标记为待复核，不冒充已验证的标注同步时间。
自动、定时下载要求程序保持运行；3090 原始库只提供 Motion，PPG 需要相应的脉搏数据接口。
真实远端服务未连接验收；HTTP 协议、完整性与任务控制通过本地模拟服务器测试。

复制实现参考 [FastCopy 公开 I/O 说明](https://fastcopy.jp/help/fastcopy_cn.htm)，采用同盘分批读写、独立设备读写重叠；未加入 FastCopy 二进制或代码。

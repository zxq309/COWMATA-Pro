COWMATA 3.7 操作指南

数据集构建

  1. 从任务栏“数据集构建”选择行为识别、产犊预测、发情预测、怀孕监测或疫病监测。
  2. 选择牧场总目录、某一类别目录，或此前导出的某一个时间戳版本。不要同时选择互相冲突的多个修订版本。
  3. 选择数据集总目录，点击“开始新版本”。目录结构为 数据集名称 / 导出时间戳 / 行为 / Motion 或 PPG / Raw、Label。
  4. 看实时数量和逐文件耗时。点击“实时记录”查看完整记录；双击已完成记录可以复核标签。暂停后用“继续当前版本”复用已完成配对。源数据或标签变化后请开始新版本。

文件名为 设备-耳标-现场标记_采集日期_采集时间_raw.json 和同前缀 _label.json。Raw 保留完整原始字节，Label 保留原记录编号。没有标注的记录列入 Unlabeled/Context，不代表负样本。历史采食保留在 HistoricalLabels；不会新增快捷键。

复核和修改

  1. 打开“历史回看”，选择现有标签文件，也可选择对应 Raw JSON。数据集记录窗口中双击已完成条目也可以打开。
  2. 单击已有标签定位时间，回看信号与匹配录像。PPG 显示原始光学通道；采样配置缺失会明确提示。
  3. 点击“修改所选标签”，修改类别、起点、终点、备注。点事件只用一个时间。
  4. 点击“保存修改到原文件”或 Ctrl+S。不会新增事件编号或新建标签文件，原始信号不会被改写；修改前保留备份。

文件被其他窗口修改时，需要重新载入后再保存。录像未连接时，可重新选择原工程或归档录像目录；没有确认的同步关系不能作为真值证据。

批量操作

在“标注与视频草稿”表中，用 Ctrl 单选追加、Shift 连选或 Ctrl+A 全选。点击“批量改标签”或“删除所选”。操作可一次撤销。点事件与区间的边界含义不同，需要逐条核对。

候选、真值和证据

操作先做什么执行结果
生成候选打开有效九轴记录，选择行为，在波形上拖选实际区间，并核对同步。生成待复核视频草稿；不会自动成为真值。
模型候选完整 V2 九轴、已核对牛号、可用模型。先运行，再看录像修正区间。模型分数不是概率；没有候选不代表没有事件。抬尾/甩尾需人工选择站立或躺卧。
确认真值选一条草稿，核对牛号、人工同步、动作起止、有效到位的视频画面。通过条件后确认该草稿。既有标签直接复核修改，不再建重复标签。
补充证据选已有记录，将原片定位到动作画面，等待画面就绪。在原记录上补充证据，保持编号。
证据截图选已有记录，选择所需视角，等待有效原片帧就绪。保存已就绪视角证据图；截图本身不确认动作区间。

视频、波形和性能

多视角选择自动网格；重点观察时切到主画面或双击放大。角速度三个轴分行，缩放波形后悬停读取实际样本。数据归类中各视角独立推进，解码/OCR 和复制按机器可用内存限制同时运行数。已归类文件直接复用；实时统计每秒合并刷新。

Excel/WPS 直接打开 CSV 是快照；软件实时记录窗口自动刷新。CSV 被外部程序独占时写入可用的实时副本，避免中断任务。

# 文件夹滚动产犊预警

手动开启后选择包含连续多日 Motion、PPG、Temp JSON 的文件夹。预测直接生成证据和结果，不要求同时提供训练数据集或产犊登记。导入的决策模型及它训练时使用的行为模型须事先可用，模型版本与哈希必须一致。

建议准备连续 3–7 天，默认目标为 3 天。这是结合当前此前 24 小时参考基线的工程建议，并非本牧场已验证的最低输入时长。一天或几小时仍可分析，界面如实显示参考历史不足；数据跨度不能替代有效覆盖，长缺口单独展示。

算法每份记录按最多 10 分钟的窗口提取证据，再按牛只时间顺序计算此前参考值。不同记录不拼造姿态连续性；未知牛号不跨记录建立个体基线。平铺目录可使用 JSON 自身 Cow ID，目录与 JSON 冲突明确列为数据问题。独立温度没有牛号时不猜测跨文件归属。

预测输出沿用导入模型的提前量（6、12、24 或 48 小时）。24 小时模型不能被解释成 6 小时模型。风险分数尚未按本牧场概率校准，不可称为准确产犊概率。信号覆盖不足时不给出分数。连续预警段表示从首次至最后一次高风险输出的记录段，未来关注窗口的截至时间不是已确认生产时间。

本模式按文件内采集时间回放，不把导入历史文件的当前时间冒充实际现场报警时刻，也不把离线回放等同于经过收包、传输延迟验证的在线告警。需通过已登记产犊时刻，按牛划分留出并验证漏报、误报/牛日、首次预警提前量。未登记结局不能自动当作负例。

打开窗口默认关闭，不自动扫描或训练；手动选择目录后运行，目录有新数据时可点击开始重新预测。结果包括综合决策结果 JSON/CSV、数据覆盖 CSV 和连续预警时段 CSV。原 JSON 不改写，不移动；标签工程不参加传感数据扫描。

研究依据用于选择待验证窗口，不照搬论文准确率：

- [2022 年尾部温度和三轴加速度多指标研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9405147/)分别建立 24 小时与 6 小时预测模型。
- [2018 年尾根表面温度研究](https://pubmed.ncbi.nlm.nih.gov/30268325/)使用此前三天同一时刻均温构造比较值，提示昼夜节律和历史长度需要考虑。本版此前 24 小时滚动基线与该研究并不相同。

# COWMATA Pro 3.9.7

原始录像每完成一段，就在校验后归档到牧场共享录像目录。新增任务耗时和最终结果表，减少 C 盘暂存、重复搬运和重复转码。

## 使用变化

- 保存位置明确显示为实际的“牧场根目录／录像／日期／视角01–20／时间戳.mp4”；“打开归类目录”进入同一位置。
- 原始码流转换在目标盘的任务专属缓存中完成。校验成功后同盘重命名提交，立即可见，不再等整个批次完成才拷贝。未完成视频不会冒充成品。
- C 盘只保留任务清单和运行记录。恢复旧任务时，逐段校验并迁移该任务的旧缓存；已经转码好的文件可复用。旧任务中尚未轮到的缓存会暂时保留，避免丢失进度。
- 增加“运行记录”“耗时明细”“归档结果”。显示读取、转换、校验、归档、总耗时、文件大小和处理方式；记录自动保存为 CSV/JSON。
- 兼容的 H.264 / H.265 整段视频优先快速封装，保留原视频码流和分辨率。需要精确中段裁切或格式不兼容时再编码，实际探测 Intel / NVIDIA，失败回退 CPU；完整解码、帧数和时间线校验始终保留。
- 暂停保留成品与当前任务；续跑核验已归档文件后复用。修复落盘与记录写入之间中断导致的重复转码。
- 已知录像机原盘直接复核同一设备，避免每段反复枚举所有磁盘。大批量表格分批刷新，减少主线程停顿。

## 速度边界

最终修订在同一段 64 分 49.72 秒真实 H.265 录像中，封装加完整校验由 768.982 秒降至 206.811 秒，文件从约 4.42 GB 降至 1.54 GB；视频码流、原分辨率和 97,243 帧保持完整。单纯封装约 15.625 秒，但完整校验仍需时间；不包含原盘提取和归档。详见 [无损视频与曲线验证](validation-397-lossless-signals.md)。此前的 [硬件编码阶段验证](validation-397.md) 保留为历史证据。

速度仍取决于原片编码、录像时长、磁盘和可用硬件。这里的录像转换速度不等同于普通 MP4 文件移动速度，不承诺任意 2,000 个视频都在 8 小时完成。

录像修复涉及原始录像准备、进度显示和交付版本信息。常规归类、传感器下载、标签与算法的业务规则沿用现有逻辑。正式原盘和原始录像保持只读。

本地提供安装包、便携包及纯净源码包；GitHub Release 仅附安装包。


同版本修订：修复暂停录像任务后重新扫描造成新旧任务冲突的问题。相同来源、范围与映射自动继续原任务；恢复按钮按当前牧场查找实际未完成任务，不再被最后一次扫描覆盖。来源变化或并发占用仍会阻止混写。

同版本修订：视频任务记录增加“总览＋各视角页签”，分别查看真实运行状态、排队、耗时和归档结果。修复已证实帧计数连续的录像机校时回拨及 PCM 音频时间戳问题，保留校时证据和同步待核对标记，成品完整解码并核对帧数。详见 [本次验证与限制](validation-397-records-clock.md)。

同版本补充：从牧场根目录打开工程或构建数据集时，排除下载隔离与恢复副本，牧场身份文件不再被作为传感器数据。旧标签迁移不再生成 PPG 占位说明文本。现有牧场文件不自动清理，先出具清单、由用户确认。详见 [目录输出与保留约定](farm-output-policy.md)。

同版本修订：转码和完整校验显示实时帧数、倍率、进度与暂存大小；受限增加解码/校验线程，明确兼容的 limited-range 源尝试 Intel 硬解码，全范围摄像头保留验证过的色彩转换。独立派包页签分别选择类别和单日/多日，日期去重汇总、明确标记、全量录像视角、可按整日设备量均衡。详见 [实测结果与适用范围](validation-397-intel-dispatch.md)。

同版本最终修订：九轴曲线避免被窗口压成细线，当前数据页签和跳转输入框更清晰，记录列表注明数据类型；旧目录 PPG 只按身份和真实重叠时间显示，明确区分时段缺口与身份冲突。详见 [曲线与保留码流修订](validation-397-lossless-signals.md)。

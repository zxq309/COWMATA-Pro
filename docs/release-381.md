# COWMATA Pro™ 3.8.1

- **修复更新兼容性。** 接受同一项目的旧仓库名和 GitHub 仓库编号重定向；仍拒绝其他仓库和越界地址。修复盘符下一级安装目录、重定向缓存目录和更新进度文件短时占用的问题。
- **旧客户端可直接运行新版安装包升级。** 安装器自动定位已注册的旧版，自带升级程序，校验解包文件和运行库后替换；失败回滚。遇到旧版地址拒绝错误时，需运行一次新版安装包，之后恢复正常更新。
- **只维护一份完整数据集。** 选择总目录后点击“更新完整数据集”，输出为“数据集名称 / 行为 / Motion或PPG / Raw、Label”。补入新增数据、复用已完成数据，更新部分来源时保留其他批次。标签变更保留内部历史，人工复核结果优先于旧来源副本；改类后清理冗余的旧分类副本。旧时间戳任务仍可继续。
- **归类记录按视角查看。** 合并为“查看归类记录”按钮，每个视角一个实时标签页；支持另存当前视角或全部记录为 CSV。

原始采集文件名中的日期、时间和设备身份继续保留。内部标签历史用于恢复，不生成整套时间戳数据副本。

安装版运行 Setup.exe；便携版完整解压后运行 COWMATA.exe。操作步骤见[实测图文教程](https://zxq309.github.io/COWMATA-Pro/operator-guide-380.html)。

源码回归：1130 项通过、9 项按环境跳过。实际数据目录核对：行为 4217 对、产犊 2449 对、怀孕 1750 对 Raw/Label，未发现缺少配对标签。抽取实际记录完成两次增量导出，第二次全部复用，输入文件哈希未变化。配对数包括不同事件目录中的同源副本，不等于独立原始记录数。

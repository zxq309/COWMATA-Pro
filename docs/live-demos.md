# 真实程序录屏

四段短视频使用实际 Windows 工作台、三个不同监控画面及真实九轴数据。程序由 Qt 自动操作，录制内容来自 GPU 桌面复制接口截取的置顶软件窗口矩形，不是拼接或生成的界面效果图。录制关闭原始音轨，避免无关声音进入公开材料。

1. `01-multiview.mp4`：A/B/C 布局、主视角切换、暂停读取精确帧、自动加载下一段录像。
2. `02-candidates.mp4`：20260906 五类模型真正运行，候选列表及质量/版本信息。空结果不解释为负样本。
3. `03-label-export.mp4`：记录区间、显式确认、输出单个可追溯的九轴片段标注文件。
4. `04-history.mp4`：独立打开历史片段，依据原记录坐标和索引线索找到录像，切换视角并在片段结束处暂停。

重要范围：录像为各监控原片生成的独立演示副本；参考时钟、与该份九轴的对应关系及标注是标明 DEMO 的操作示例，不代表这些录像已经与该牛、该次采集科学对齐。原始画面中的时间仍可见。不能据演示标签训练模型或评价模型准确率。

录屏脚本为 `scripts/record_release_demos.py --project <隔离演示工程> --out <全新输出目录>`，须使用带 `DEMO-ONLY.json` 标记的私有演示工程；拒绝对普通生产工程直接录制。原始素材与示例标注 JSON 不公开上传。`recording-report.json` 核验真实操作、模型结果、跨文件及导出过程。截图使用同一 GPU 捕获方法，避免普通 GDI 漏掉硬件解码画面。

录屏有额外 GPU/编码负载，不拿演示视频代替压力测试报告。最终发布测试单独进行。

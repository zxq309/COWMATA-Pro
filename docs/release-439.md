# COWMATA Annotator 4.3.9

本版以《样本试验台账》为核心，在牛佩戴设备期间下载预测数据。

## 操作步骤

1. 在现场台账上传器中关联最新样本 Excel，补录后保存 Excel，再点击同步。现有上传器 1.4.5 已支持空佩戴结束和补录，无需更换上传协议。
2. 在主软件的下载窗口刷新台账。设备号必须为 12 位十六进制，牛号和佩戴开始日期时间必须有效。
3. 佩戴结束为空的记录进入下载队列。产犊起止、九轴、脉搏、温度的有效性暂未填写，不影响下载资格。
4. 选择手动、自动或定时下载。仍沿用原有时间范围：每轮最多下载到北京时间当天零点，当天数据由下一天的任务补齐。
5. 在下载根目录的 `待预测` 文件夹查看原始数据和 CSV 清单。

## 保存位置

```text
下载根目录/
  待预测/
    Motion/日期/设备-耳标-现场标记/*.json
    PPG/日期/设备-耳标-现场标记/*.json
    Temp/日期/设备-耳标-现场标记/*.json
    待预测清单.csv
    预测台账.csv
  .edge-download/
    prediction-tracking.json
    prediction-csv-history/
```

`待预测清单.csv` 包含仍在佩戴的记录；`预测台账.csv` 保留全部已跟踪记录，包括后来结束佩戴的记录。CSV 中的已下载文件数和原始数据路径对应本地文件，没有原始文件时为 0 和空数组，不代表已经收到数据。

CSV 使用 UTF-8 BOM，便于 Excel 打开。算法可以按 `记录ID` 关联结果；该标识由完整设备号、耳标和佩戴开始生成，不受行号、排序、现场标记或后补产犊信息影响。用户或算法新增的预测结果列在刷新时保留；退出待预测清单前的旧清单另行归档。程序不覆盖独立预测结果文件。

## 补录如何处理

- 第一次读取时已经有佩戴结束的历史记录，不创建新的下载任务。
- 已跟踪记录后来补上佩戴结束，继续补齐佩戴开始至结束间尚未完成的数据，完成后不再新增下载范围。失败和取消不会算作收尾完成；重启后继续处理。
- 当天补上的结束时间，需要等待原有“下载至昨日”范围覆盖结束时刻后，才能完成收尾。
- 后补产犊信息更新同一条预测台账，并保留原始数据及补录前的元数据历史。佩戴结束只表示设备已摘下，不表示产犊。
- 空白、`/`、`待定` 和有效时间分别保留。非空但无法解释的佩戴结束不会当成仍在佩戴。
- 同一佩戴身份存在互相矛盾的结束时间时暂停该记录并提示核对，不根据行排序选择其中一条。
- 另外两张台账用于辅助核对。它们刷新失败时保留旧副本并提示；核心样本台账失败、授权失败或取消时停止本轮。

本版提供原始数据和预测清单，供独立产犊预测程序读取。未在下载器内启动模型训练或自动计算预测准确率。产犊标注和传感器有效性是独立状态，不用底色或空值推断真实结局。

# COWMATA 3.4.2

在 3.4.1 基础上，贯通“数据归类 → 人工标注 → 算法数据集”。怀孕批次须选择孕早期、孕中期或孕晚期；产犊仍为单一类别，人工干预等信息保存在元数据中。

“数据整理 → 旧标签迁移”支持旧 CSV/BORIS 标签，预览后生成可继续编辑的工程和新版单文件标注。设备、五位耳标、现场标记与原始文件来源可追溯。牛号冲突保留待核并排除训练；缺失时间不补造。缺少九轴的产犊绝对时刻可独立回看，不生成虚构波形。

“从标注生成算法数据集”优先读取当前已保存的标注，删除的标签不会从旧导出快照复活。完整原始九轴按哈希保存，母标签支持重叠点/区间；起立、卧倒、排尿、抬尾、甩尾沿用已有算法特征接口，综合决策生成连续温度和活动量输入。全部算法共用按牛划分，窗口不改变原始数据。

可选导入历史算法数据集，保留旧特征并建立逐行来源对应。未标注候选、代理负样本与人工确认负例分开保存。代理负样本默认不进入训练；经用户明确选择后仅限训练，不能作验证或测试真值。各算法的 readiness.json 列明是否具备训练输入条件，质量未通过或没有匹配候选的事件继续保留待核。

PPG 继续预留目录、母标签和数据集字段。此前的空格播放、零时长区间拦截、最新标签选择与拖动调整功能保留。修复实际窗口测试发现的 Qt 完成信号重名问题，后台预览完成后界面可正确进入下一步。

源码、完整便携包、安装包和更新描述文件同时发布。图文教程加入本版实际 Windows 窗口截图。数据规范及命令行训练入口见 [操作说明](https://github.com/zxq309/COWMATA-Pro/blob/main/docs/legacy-dataset-workflow.md)。训练入口只写新研究模型，不替换随包模型或自动上线。

# COWMATA Pro 3.8.3：一次对齐与旧版升级修复

接续 3.8.2，保留算法管理、三个事件模型与产犊证据功能。

## 一次对齐

1. 在波形右上角点击“一次对齐”。软件暂停播放，暂时关闭同步跟随。
2. 分别拖动录像和九轴，让同一动作的同一时刻位于各自播放线上。
3. 点击“完成对齐”，自动恢复同步跟随，即可继续标注、保存及确认导出，无需第二次对齐。

一次对齐以固定时间差同步当前这份九轴记录，不改变播放速度。切换视角或同一路的小视频无需重复对齐；重新打开会恢复已保存的校准。另一份记录仍使用自己的校准。

若越播偏差越大，可在对齐栏切换“精细校准：增加对应点”校正时钟漂移。原有两点、多点校准仍可正常使用。重新对齐保留历史和撤销能力，已有标注坐标不移动，已确认标注需要重新复核。

自动设备时间和历史单个粗定位点不会被直接当作新的一次对齐。未确认时间段、画面未到位、牛号冲突等检查继续有效。导出中记录 offset 对齐方式，便于区分固定时间差与多点漂移校准。

修复校准表打开后直接保存时丢失毫秒及原画面来源的问题。

## 修复 3.8.0 更新卡住

旧客户端安装在例如 D:\COWMATA Pro™ 时，点击“保存退出并更新”可能报 Refusing a broad installation target：旧目录保护错误拒绝了盘符下一级的正规安装目录。

这种旧客户端需要运行本次 Setup.exe 完成一次兼容升级。新版安装器和更新器会核对软件身份、文件清单及注册目录，允许正规安装位置；仍拒绝盘符根目录、链接目录和混入用户文件的安装目录。

先正常保存并关闭旧窗口，再运行安装包。安装器在原目录升级，保留工程数据与设置。之后可以继续使用软件内“保存退出并更新”。本版新增了盘符下一级目录的准备更新回归测试。

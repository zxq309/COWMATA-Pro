# COWMATA Annotator 3.6.3 纯净版

本版仅交付源码 ZIP 和已解压便携文件夹，不发布 GitHub，不生成安装程序。

1. 双击便携文件夹内 COWMATA.exe，打开“工具 → 数据归类”。
2. 第一步选择牧场目录和类别；选择 JSON 与视频一起归类，或已有 JSON 补充视频。
3. 第二步选择包含所有视角的视频总目录。各视角自动列出，默认不勾选；只勾选需要处理的视角，也可全选。JSON 一起归类时另加 Motion / PPG 来源。
4. 点击“一键归类”。每个所选视角有独立的复制/移动队列；各路同时传输，进度单独显示。实际吞吐取决于磁盘和解码能力，机械盘并行不保证线性提速。
5. 全零或空文件在完整核验后立即删除；整段每一帧均为黑画面、或解码器确认结构损坏/无法解码的录像也会删除。正常暗画面、短暂黑帧不会作为全程黑屏删除。占用、权限、读取超时和解码环境问题会保留并报告，不能当成文件损坏。
6. 已归类且来源与目标身份未变化的文件直接复用，不重复识别、哈希或复制。新文件的完整健康核验结果按文件身份缓存；内容变化后重新核验。
7. 点击“暂停”可保留各路断点；继续时只处理当前勾选来源。相同内容仍共用一个已验证归档目标。删除记录在继续本任务后保留，重新出现的同名文件会重新核验。
8. “打开实时 CSV”内的窗口每秒刷新，每文件一行，显示总数、归类、复用、删除、待处理、异常和单文件耗时。Excel 直接打开 CSV 是静态快照，实时查看使用工具内窗口。

视频仍按识别到的采集日期归入 Video/日期/视角；不能凭目录日期猜造时间。单文件耗时包含识别、核验和传输；总任务耗时另行显示。黑屏核验需完整解码，首次检查耗时取决于视频时长；复用或健康缓存命中时免重复解码。

便携目录保留端侧数据下载、标注、复核与既有模型能力；不携带个人配置、密钥、日志、下载记录、用户录像或测试素材。

程序接口兼容原有只读检查和旧任务：新的操作员归类请求显式设置 delete_unusable=true；未设置此选项的旧 API 调用继续保留异常原件。

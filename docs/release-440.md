# COWMATA Annotator 4.4.0（发布包 COWMATA-Pro-4.4.0）


### 一个窗口，按工作顺序
- 主菜单改为 **文件 / 编辑 / 上传 / 下载 / 标注 / 工具 / 帮助**，对应“打开工程 → 上传台账 → 下载数据 → 标注 → 工具”。
- 4.3.9 的全部命令逐一迁入新菜单：处理函数、快捷键、启用条件不变；新增测试检查“无遗漏、无重复、最多两级”。
- 新增快捷键：Ctrl+U 台账、Ctrl+D 端侧数据、Ctrl+F 查找记录、Ctrl+W 关闭工程、Ctrl+Q 退出。
- 视频、时间同步、录像索引、视图等移入 **工具**；**标注** 只保留标注本身。

### 上传：现场台账内置
- “COWMATA 现场台账”上传器（1.4.6）整体内置为 **上传** 菜单：导入表格、同步修改、刷新服务器、新建记录、核对冲突、统计报告、导出 CSV、四张表、上传设置。
- 使用本软件的登录会话签名上传，不再单独登录；关闭台账窗口不会退出软件。
- 修复：Excel 合并单元格（同一头牛多行）在表格中显示为空的牛号、预产期（109 行）。

### 待产犊（上传、服务器、下载同一规则）
- 产犊开始、结束均为空 → **待产犊**（尚未产犊）；原来混在“待核对”中。服务器现有数据：待产犊 93、孕晚期 388、产犊 148、待核对 5（真实格式错误）。
- 死胎 / 难产 / 产后监测却未填产犊时间 → 待核对（已分娩，时间缺失）。
- 台账新增第四张表“待产犊”；服务器生成 `待产犊台账.csv` 和 `待产犊变更记录.csv`，补填时间后自动移出。
- 分类由规则统一推导，服务器比对前重算，旧客户端残留的分类不会造成重复上传。
- 下载：待产犊佩戴期间持续下载；分类变化后九轴、PPG、温度三类数据一起移动；同一头牛未补全的记录不再把已确认记录拖成“待核对”。

### 账号
- 账号按姓名拼音命名；管理员“添加用户”自动生成 8 位密码和一次性密钥并复制。
- 同一账号同时写入标注与上传两份账号表；服务器写台账改为检查 upload 权限。
- 登录窗口：操作员 / 管理员分段选择；账号菜单移到 帮助 → 账号。

### 界面
- COWMATA 品牌色（#8ADD66 / #35AFC8），iOS 式字号、间距、圆角；分段控件统一。
- 界面文字精简；新手图文教程按 4.4.0 重写（帮助 → 新手图文教程）。
- 修复：内置台账窗口中 28 像素图标按钮因内边距显示为空白。

### 测试
- 新增 `test_annotator_shell_440`、`test_named_accounts_440`、`test_pending_calving_440`；菜单相关测试按新菜单更新。
- 全量：2195 通过；剩余 2 项为历史英文翻译覆盖（703 条，4.3.9 为 713 条）。

配套：现场台账上传器 1.4.7（独立安装的用户经 ledger-latest 签名通道自动升级，规则与本软件一致）；科牧特产犊预测算法 4.4.0。

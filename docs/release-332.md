# COWMATA Annotator 3.3.2

本次针对客户反馈修复三项问题，保留既有标注、播放和导出流程。

1. **待确认有解释**：鼠标悬停“状态 / 开始时间”即可看到原因及下一步；区分未完成索引与需要人工核验时间。
2. **检索不反复从头开始**：同一九轴时间范围的刷新不再重启 OCR；难识别画面限时保留待复核，继续查找其他录像。后台抽查文件并不表示已匹配当前牛。
3. **区间范围一眼可见**：闭合标签和能映射到当前九轴的视频草稿默认显示淡色背景及两端边界；草稿虚线表示待复核，仍支持拖动两端、编辑时间、撤销和保存恢复。

下载 **Setup.exe** 安装；或完整解压 **Portable.zip** 后运行 COWMATA.exe。**Source.zip** 为纯净源码，**Manual.pdf** 为图文说明书。已有安装版直接检查最新版，无须逐版更新。

验证范围、客户原片限制及结果见[验证记录](https://github.com/zxq309/COWMATA-Pro/blob/v3.3.2/docs/release-332-validation.md)；最终安装和升级证据随发布附件 Delivery-Checks.json 提供。

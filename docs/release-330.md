# COWMATA Annotator 3.3.0

本次统一“整理数据 → 标注保存 → 复核导出”，修复旧工程 pending 与视频空白问题。普通用户下载 **COWMATA-Annotator-3.3.0-Setup.exe**；自动生成的 Source code.zip 是开发源码。

1. **后台整理数据**：支持单设备、单份、单日和多日九轴与多视角视频。先审查再剪切，视角统一为01～08；同工程先保存暂停，其他工程可继续标注。中断可续接，异常原件保留。
2. **统一目录身份**：使用“完整设备编号-牛耳标号-现场记号”。异常名称先提示核对；不猜测改名，不把有效九轴当废料。设备跨日期复用按每份记录保存，不混牛、不按设备号删重。
3. **七类数据贯通**：正常健康、发情、孕早期、孕中期、孕晚期、产犊、疫病。所有类别均可自由标行为；保存、片段、CSV、训练导出和团队回传保留类别及来源身份。
4. **修复加载和索引**：旧名称分组不再导致记录消失；首帧无时间可继续读取后续帧；兼容3.1旧索引；同路径更新文件可重试；空画面点击播放不会暂停检索。素材状态窗口实时刷新。
5. **补齐标注衔接**：保留人工牛号并提示身份冲突，修复回传类别同步、时间戳导出和证据图片路径。九轴波形、标注列表与历史回看统一显示对应时间戳；窄窗口减少刻度避免重叠。修复 Windows 文件暂时占用时保存失败、重复结束动作可能重复写入，以及八视角历史窗口集中创建造成的停顿；大份回收和训练导出在后台执行。
6. **更新与说明书**：保持启动检查最新版、自动更新后再使用的规则；修复损坏下载重试、回滚与重复更新。帮助和关于均可打开 **32页图文操作说明书**，使用当前界面38张实拍截图，按整理、标注、复核导出逐步说明；每页三个短步骤，带目录书签。

安装组件、五类事件模型和 OCR 权重随包提供。启动检查需联网，已打开的工程可离线继续。没有更新器的早期版本仍需手动安装一次；具备更新器的旧版直接获取最新版本。

验证结果与实际运行范围见 [功能实测](https://github.com/zxq309/COWMATA-Pro/blob/main/docs/release-330-validation.md)，代码审查见 [审查报告](https://github.com/zxq309/COWMATA-Pro/blob/main/docs/code-audit-330.md)。客户出问题的原始工程在客户电脑，本机采用对应结构复现；不宣称已验证该客户原件或所有硬件条件。

健康与繁殖分类是人工采集分组，不是自动诊断；未接入的算法仍显示待接入。首次从旧版本升级执行旧版更新器，新版恢复保护从安装3.3后生效。

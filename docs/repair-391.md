# 3.9.1 本地修复版

本次仅提供源码 ZIP、便携 ZIP 和解压目录，不包含安装器，未发布到 GitHub。

## 快捷键

主标注页面与候选列表使用同一套标签键。区间按一次开始、再次按同一键结束；点事件按一次记录。

| 键 | 标签 | 类型 |
|---|---|---|
| 1 | 起立过程 | 区间 |
| 2 | 卧倒过程 | 区间 |
| 3 / 4 | 站立抬尾 / 站立甩尾 | 区间 |
| 5 / 6 | 躺卧抬尾 / 躺卧甩尾 | 区间 |
| 7 | 努责 | 区间 |
| 8 | 胎膜囊（水囊）首次可见 | 点 |
| 9 | 胎儿首个部位首次可见 | 点 |
| A | 犊牛完全娩出 | 点 |
| B | 胎膜完全排出 | 点 |
| C / D | 排尿 / 排便 | 区间 |
| E / F | 爬跨 / 助产 | 区间 |

打开旧工程后显示当前标签，历史标签继续保留。旧事件按稳定标签代码重新关联，时间、编号和原始文件保持原值。按键后选框显示实际记录的动作，长按不会连续生成标注。模型辅助标注中的“显示全部波形”改用 Ctrl+Shift+F，避免与助产冲突。输入牛号、搜索文字和时间时优先输入文字。

## 三个目录

- 原始下载：`F:\扬大_高邮牧场`，其下仍按分类 / Motion、PPG、Temp、Video / 日期 / 设备-耳标-现场号组织。
- 现场 CSV：`F:\牛舍\_现场记录`。
- 模型库：`F:\科牧特\_模型`，行为识别和产犊决策分别保存。

已配置的其他牧场目录不会被升级覆盖。仅修正 3.9 曾强制写入的 "F:\牛舍" 默认值。识别与决策窗口从下载器读取原始输入路径。未选择有效训练目录时不创建训练输出。

现场已有的误落盘数据保留原位置；不要删除它们或直接覆盖同名文件。

## 更新修复

检查发布信息和读取正文遇到 TLS EOF 会进行有限重试；Windows 上 Python TLS 连接中断时使用系统 WinHTTP 通道和系统代理配置。HTTPS 证书校验、官方域名限制、SHA-256 校验及断点续传继续生效。403 限流仍通过官方发布订阅和附件页查询。

技术依据：[Microsoft WinHTTP 系统代理说明](https://learn.microsoft.com/en-us/windows/win32/api/winhttp/nf-winhttp-winhttpopen)。

本地回归与真实公网下载是不同验证。当前任务网络受限，真实公网下载验证尚待恢复权限；详细结果见验证记录。

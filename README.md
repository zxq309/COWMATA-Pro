# COWMATA Annotator 4.4.4

**奶牛尾环数据工作台**：打开工程 → 上传台账 → 下载端侧数据 → 标注 → 工具。一个账号、一个窗口。

## F:\ 目录（4.4.1 起所有路径按此对齐）

```
F:\1_下载器\扬大_高邮牧场\        原始数据：产犊 / 待产犊 / 怀孕\孕晚期 / … + 台账\*.csv + 录像
F:\2_标注器\CowMata Annotator\    本软件各版本（安装包 / 便携包 / 源码包）
F:\2_标注器\科牧特_协作标注\       协作数据包
F:\3_训练器\产犊\                  算法 · 数据集 · 模型 · 训练结果
F:\4_决策器\产犊\                  预测算法（决策器）· 决策结果 · 前端APP
```

软件首次启动自动把旧位置（`F:\扬大_高邮牧场`、`F:\牛舍_现场记录`）换到上面的结构；自动标注模型默认查找 `3_训练器\产犊\模型\<最新版本>\行为识别`。

## 下载：一个按钮

- **下载**：按样本试验台账自动下载（九轴、PPG、温度），按台账分类保存；下载到当前时刻，每轮结束 1 分钟后继续。
- **暂停**：停止本轮并删除未完成的临时文件；再点“下载”从断点继续（已下载的完整文件自动跳过）。
- 打开下载器和每轮开始时，先核对 **待产犊**：台账已补产犊时间的，文件立即移到 **产犊** 或 **孕晚期**；仍为空的留在待产犊。
- 下载期间自动启动 **决策器**（`4_决策器\产犊\预测算法\<最新版本>`，与训练器分开，加载训练器模型的拷贝）：某头待产犊的牛有新的完整 JSON，即重新决策，结果写到 `4_决策器\产犊`，“下载 → 决策 APP”查看。

## 台账分类（上传、服务器、下载同一规则）

| 产犊开始 / 结束 | 归类 |
|---|---|
| 均为空（产犊监测 / 孕后期监测） | 待产犊 |
| 时间在佩戴期内 | 产犊 |
| 填“/”，或产犊发生在拆除设备之后 | 孕晚期 |
| 只填一项、先后颠倒、格式错误；死胎 / 难产 / 产后监测却未填时间 | 待核对 |

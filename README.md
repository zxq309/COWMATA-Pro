# COWMATA Annotator 4.4.0

**奶牛尾环数据工作台**：打开工程 → 上传台账 → 下载端侧数据 → 标注 → 工具。一个账号、一个窗口，完成现场一天的工作。

> 4.4.0 起，“COWMATA 现场台账”上传器内置于本软件（菜单 **上传**），与 **下载** 使用同一套分类规则；样本试验台账新增 **待产犊**。
> 已安装的 COWMATA Pro / Annotator 4.3.x 可在“帮助 → 关于 → 检查更新”原地升级，工程、标注与设置保持不变。

## 菜单

| 菜单 | 内容 |
|---|---|
| 文件 | 打开工程 / 九轴 / 视频 / 协作数据包、历史回看、保存、导出（完整成果 / 所选片段 / 训练数据）、关闭工程、退出 |
| 编辑 | 撤销、重做、修改标签、批量修改、删除、查找记录 |
| 上传 | 台账、导入表格、同步修改、刷新服务器、新建记录、核对冲突、统计报告、导出 CSV、表（样本试验台账 / 产犊登记 / 设备台账 / 待产犊）、上传设置 |
| 下载 | 端侧数据、更新台账并下载、停止下载、数据归类（录像转码与归类 / 常规归类 / 继续上次归类 / 归类记录）、下载设置、下载记录、检测连接 |
| 标注 | 自动生成候选、用所选区间建立候选、逐项检查、自动标注模型、完成本份 / 下一份 / 重新标注、确认为真值、留存证据图、协作 |
| 工具 | 时间同步、录像（索引、核验、导出标准 MP4）、视图、性能诊断、硬件解码、旧版兼容、设置 |
| 帮助 | 快速开始、新手图文教程、账号、关于 |

## 台账分类（上传、服务器、下载同一规则）

| 产犊开始 / 结束 | 归类 |
|---|---|
| 均为空（产犊监测 / 孕后期监测） | **待产犊**：尚未产犊，佩戴期间持续下载 |
| 时间在佩戴期内 | 产犊 |
| 填“/”，或产犊发生在拆除设备之后 | 孕晚期 |
| 只填一项、先后颠倒、格式错误；死胎 / 难产 / 产后监测却未填时间 | 待核对 |

服务器每次写入样本试验台账后，重新生成 `待产犊台账.csv`，并在 `待产犊变更记录.csv` 追加新增 / 移出 / 删除 / 修改。

## 账号

- 账号用本人姓名拼音（如 `zhangxiangqing`），同一账号登录标注、上传、下载。
- 管理员：帮助 → 账号 → 用户与密钥… → 添加用户。自动生成 8 位密码和一次性密钥，并复制到剪贴板。
- 一次性密钥只用于新电脑首次登录。

## 自动标注用哪个模型

1. 环境变量 `COWMATA_ALGORITHM_HOME`；
2. “标注 → 自动标注模型…”选过的目录；
3. 本机数据目录 `models\行为识别`；
4. 自动查找 `科牧特_模型\<最新版本>\行为识别`。

候选不是真值，需人工确认。

## 安装与升级

- 安装包 `COWMATA-Pro-4.4.0-Setup.exe`（NSIS，用户级，默认 `%LOCALAPPDATA%\Programs\COWMATA Annotator`）；
- 便携包 `COWMATA-Pro-4.4.0-Portable.zip`（解压后双击 `COWMATA.exe`）；
- 源码包 `COWMATA-Pro-4.4.0-Source.zip`。

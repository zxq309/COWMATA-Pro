# Security policy

## Supported version

Security fixes target the latest release and the current `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability-reporting flow at <https://github.com/zxq309/COWMATA-Pro/security/advisories/new> when available, or contact the repository owner privately through the organization channels listed at <https://www.cowmata.com/>.

Include the affected version, impact, reproduction steps, and any safe proof of concept. Remove farm recordings, personal information, credentials, and proprietary model/data files before sending evidence.

The maintainers will acknowledge a usable report, validate its scope, prepare a fix, and coordinate disclosure. Please allow time for investigation before publishing details.
